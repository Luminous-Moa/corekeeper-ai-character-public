## 개요

AI 캐릭터가 존재하는 월드에서 채팅·목록 조회 흐름의 한 관측 상태.

## 화면 흐름

Return으로 입력칸을 열고 /ai를 입력·제출하면 에코와 목록/짧은 명령 안내가 남는다. 다시 Return으로 입력칸을 열 수 있다. /ai Claude 초안은 Escape로 취소했다. 채팅 위 휠 시도에서는 로그가 움직이지 않고 퀵슬롯이 바뀌었다. 문자열·출력·슬롯 변화는 같은 화면의 요소 상태다.

- E02: 월드에서 Return → 기존 메시지와 빈 입력칸을 봄. 다음 관측은 /ai 입력.
- E03: 빈 입력칸에 /ai 입력 → /ai가 입력칸에 보임. Return 제출 후 목록 결과로 이동.
- E04: /ai 입력 후 Return → 제출 에코와 목록/도움말을 봄. 입력칸은 닫혀 있음.
- E05: 결과 화면에서 Return → 결과를 보면서 새 명령을 입력할 수 있는 칸이 열림.
- E06: 빈 입력칸에 /ai Claude 입력 → 대상 지정 문자열만 보임. 다음 Escape로 취소; 실행 결과 없음.
- E07: 대상 초안 상태에서 Escape → 입력칸이 닫히고 기존 /ai 결과는 남음.
- E08: 결과 화면에서 Return → 결과와 빈 입력칸을 다시 봄. 다음 조작은 채팅 위 휠.
- E09: 채팅 영역 위로 600 스크롤 → 로그 위치는 그대로이고 슬롯 0 선택 테두리가 보임.
- E10: 채팅에서 Escape → 입력칸이 닫힘. 기존 결과와 슬롯 0 테두리가 남음.

### 1. 중앙 월드 장면

ID: `CKAI-02#1`

문구 없음(그림/아이콘).

### 1-1. Claude 이름표와 캐릭터

ID: `CKAI-02#1-1`

이름표와 캐릭터의 시각적 결합은 관측. 동작 원인/목표는 화면만으로 알 수 없음.

```text
Claude
```

### 1-2. 코어 앞 다른 캐릭터

ID: `CKAI-02#1-2`

A1의 플레이어 지칭을 참조. PNG의 이 캐릭터에는 이름표가 없어 Luminous와의 동일성은 독립 확정하지 않음.

문구 없음(그림/아이콘).

### 2. 채팅 로그

ID: `CKAI-02#2`

상단 일부는 공통 HUD에 가림. 이번 탐색 전 행동 결과이며 전투를 재검증한 것이 아님.

문구 없음(그림/아이콘).

### 2-1. 쓰러짐·대상 수치 로그의 보이는 부분

ID: `CKAI-02#2-1`

첫 줄과 아래 연속 구간만 전사. 첫 줄 뒤와 MushroomEnemy 앞의 가려진 문구는 누락했으며 전체 원문으로 간주하지 않음.

```text
AI 쓰러짐 #40: (-4,-1).
MushroomEnemy 3.3
hp70, MushroomEnemy 7.1
hp105, MushroomEnemy
7.3 hp105)
```

### 2-2. 공격 완료 메시지

ID: `CKAI-02#2-2`

〔기호 불확실〕은 편집 표기이며 화면 문구 아님. A1 전사는 70→70이나 원본 픽셀에서 두 숫자 사이 기호를 확정하지 못함.

```text
AI 공격 완료:
MushroomEnemy 처치
(체력 70〔기호 불확실〕70) (3.9초)
```

### 3. 채팅 입력칸

ID: `CKAI-02#3`

```text

>/ai
```


### 2-7. AI 목록과 생략된 명령 안내

ID: `CKAI-02#2-7`

줄바꿈은 PNG 기준. '없음' 필드의 의미 및 … 뒤 전체 명령은 미확인. 이 화면만으로 개별 명령의 지원/효과를 확정하지 않음.

```text
있지 않음 · 명령: /ai
<〔인자명 판독 불확실〕> on|off|goal …
```
