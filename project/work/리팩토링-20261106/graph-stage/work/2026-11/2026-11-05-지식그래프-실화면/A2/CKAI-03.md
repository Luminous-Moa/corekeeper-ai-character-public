## 개요

월드를 나가지 않고 게임 메뉴와 접속 플레이어 표시를 확인하는 상태.

## 화면 흐름

A1 E12에서는 메뉴 항목과 접속 플레이어 목록만 보고 항목 실행 없이 Escape로 복귀했다. A3에서는 플레이어 관리를 클릭한 뒤 SPACE로 CKAI-04에 진입했고 E14 원본으로 상세 화면을 확인했다.

- E12(A1): 월드에서 Escape → 메뉴 항목과 접속 플레이어 목록만 확인하고 항목 실행 없이 Escape로 복귀.

## 화면요소

번호는 매칭본과 동일. 파란 H 번호는 공통 HUD의 번호이며 별도 노드가 아니다. 문자열·로그·슬롯 변경은 같은 화면요소의 상태다. 좌표는 증거별 manifest에 있다.

- 조건 / 주체 / 행위: 관측된 게임 메뉴 열림 상태에서 / 메뉴 화면 / 세계 정보·접속한 플레이어·메뉴 항목·버전을 보여 준다.
- 한계: A1과 A3의 관측된 키 입력·진입만 확인. 유지 시간, 실패 조건, 네트워크/로컬 처리 및 다른 상태의 규칙은 미검증.

## 요청·기능 연결 근거

[A1 조작 기록](../A1/observations.json) 및 [A3 실제 조작 보고](../A3/new-user.md)·[E14 원본](../A3/new-user-05-player-management.png)는 키 입력과 전후 화면 근거다. HTTP/IPC/상태 코드/스트림 기록이 없어 기능 ID·처리 위치는 추정 연결하지 않는다. 도움말 노출은 개별 명령의 실행 성공 증거가 아니다.
