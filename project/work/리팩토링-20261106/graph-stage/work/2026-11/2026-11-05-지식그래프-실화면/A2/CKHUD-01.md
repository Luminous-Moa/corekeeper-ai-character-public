## 개요

월드 탐색 중 상태 막대, 미니맵, 퀵슬롯을 본다. 세부 효과는 실행하지 않았다.

## 화면 흐름

09/10은 슬롯 0 선택, 나머지 월드 캡처는 슬롯 1 선택. 상태별 선택 차이는 각 원본이 정본이다.

- E01: 기존 Core Keeper 창 활성화 → 월드와 Claude 이름표를 봄. 다음 관측은 Return으로 채팅 열기.
- E02: 월드에서 Return → 기존 메시지와 빈 입력칸을 봄. 다음 관측은 /ai 입력.
- E03: 빈 입력칸에 /ai 입력 → /ai가 입력칸에 보임. Return 제출 후 목록 결과로 이동.
- E04: /ai 입력 후 Return → 제출 에코와 목록/도움말을 봄. 입력칸은 닫혀 있음.
- E05: 결과 화면에서 Return → 결과를 보면서 새 명령을 입력할 수 있는 칸이 열림.
- E06: 빈 입력칸에 /ai Claude 입력 → 대상 지정 문자열만 보임. 다음 Escape로 취소; 실행 결과 없음.
- E07: 대상 초안 상태에서 Escape → 입력칸이 닫히고 기존 /ai 결과는 남음.
- E08: 결과 화면에서 Return → 결과와 빈 입력칸을 다시 봄. 다음 조작은 채팅 위 휠.
- E09: 채팅 영역 위로 600 스크롤 → 로그 위치는 그대로이고 슬롯 0 선택 테두리가 보임.
- E10: 채팅에서 Escape → 입력칸이 닫힘. 기존 결과와 슬롯 0 테두리가 남음.
- E11: 숫자 1 → 슬롯 1 선택으로 돌아옴. 캡처에서 채팅 텍스트는 보이지 않음.
- E13: 메뉴에서 Escape → 채팅·메뉴가 닫힌 월드를 유지. 이후 입력 없음.
