# 필요한 경험과 게임 지식을 찾아 다음 판단에 쓰기

> 통합 기획: 기존 의도와 기준 코드 e82eb87, 격리 HTTP 관측을 구별한다. 게임 화면 확인은 사용자 지시로 후속 유예했다. 새 사용자 결정은 없다.

## 무엇을 하는가

위쪽 LLM을 쓰는 AI — 자기 캐릭터가 아는 기억을 필요한 만큼 찾아 판단에 쓴다.

## 언제 하게 되나

문제: 목차만으로는 다음 목표를 고를 사실이 부족하다.

상황: 보고의 memory_index를 받고 자세한 사실이 필요할 때.

## 차례

1. 시작: 경험과 기억 목차를 받는다. 화면요소 ID: **미확정**(게임 화면/정상 AI 출력은 이번에 관측하지 않음).
2. 필요하면 recall 질의를 내고 브리지의 결과를 받는다. 화면요소 ID: **미확정**(게임 화면/정상 AI 출력은 이번에 관측하지 않음).
3. 분기: 한 판단 검색 최대 2번 등의 정책 안에서 결과를 쓰며, 상한·마감 뒤에는 목표 결정을 낸다. 화면요소 ID: **미확정**(게임 화면/정상 AI 출력은 이번에 관측하지 않음).
4. 끝: 모드로 전달되는 set/hold/ask 결정을 만든다. 화면요소 ID: **미확정**(게임 화면/정상 AI 출력은 이번에 관측하지 않음).

출력 문서 예약: OUT-03, OUT-05. 이 참조는 화면요소 연결이 아니다.

## 얻는 것

자기 관측 범위에 속하는 과거 사실과 게임 지식.
