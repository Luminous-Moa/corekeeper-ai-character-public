# C-3 처음 온 운영자 검증 입력

시작 상황: AI 동료를 쓰기 전에 로컬 연결의 준비 상태를 확인하려는 운영자다. 계정·게임 월드 상태는 주어지지 않았다.

화면 한 줄: `http://127.0.0.1:18331/v1/health`는 브리지의 현재 준비 상태를 JSON으로 확인하는 출력이다.

유저 활동: 연결 준비 상태를 확인하고 다음 행동을 판단한다.

1. 위 주소에 GET을 보내 응답 도달 여부를 확인한다.
2. 응답 본문의 전체 상태와 구성원별 상태를 읽는다.
3. HTTP 응답 성공과 AI 사용 준비 여부를 구별해 판단한다. 설명이 없는 필드는 모른다고 남긴다.
4. 응답에서 준비가 확인되면 그 근거를 적는다. 준비가 확인되지 않으면 응답이 안내하는 다음 조치를 찾고, 안내가 없으면 무엇이 부족한지 적는다.
5. 얻은 것·얻지 못한 것과 여기서 마칠지의 이유를 적는다.

검증 범위: 글대로 됐는지, 글로는 쉬워 보였는데 실제 출력에서 어려웠던 곳. 새 HTTP GET 결과를 근거로 한다. 소스·기존 탐색 기록·전체 화면설계서·다른 에이전트 보고는 읽지 않는다.

실행 제한: localhost:18331의 GET만 허용. 외부 호출·유료 모델·로그인·설정/계정/게임/운영 상태 변경·POST 금지. 실게임 화면 확인은 사용자가 후속 유예했다. 산출물은 이 C3 폴더의 raw 원문과 report.md만 쓴다.
