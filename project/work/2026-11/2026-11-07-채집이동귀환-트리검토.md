# 채집·이동·귀환 선택 구조 검토

후속 상태: 아래는 당시 검토 기록이다. 이후 사용자가 얕은 분류 트리와 직접 실행 병행 권고를 수용했다. 현재 기준은 [확정 합의](2026-11-07-채집이동귀환-확정합의.md)이며, 구현은 사용자 지시로 대기 중이다.

## 맡은 범위와 현재 질문

이 대화는 채집·이동·귀환을 맡는다. 이번 단계는 기존 생활 선택 트리의 취지와 비교해 이 영역에도 트리가 필요한지 판단하는 것이며, 구현 방식은 아직 사용자 확정 전이다. 제품 코드·설치·게임 상태를 변경하지 않는다.

## 확인한 기존 기준

- [기본 행동 정비 순서](2026-11-07-기본행동-정비순서.md): 고정 허용 목록 밖 채집 품목, 목표 외 자원 비교, 발견 기록, 귀환까지 실제 실행과 결과 관측으로 연결한다.
- [가방 트리 합의](2026-11-07-가방장비구현/tree-agreement.md): 분류부터 실제 항목을 고르는 다단계 상태, 뒤로·선택 전체 취소, 임의 후보 상한 제거가 사용자 결정이다. 채집 전체 트리 재설계는 해당 담당 범위 밖이다.
- 생활선택-트리구현 기록: 탐색 중 현재 행동·부탁 보존, 직접 실행과 단계 탐색의 병행, 공통 실행 계약 재사용을 승인했다.
- 원래 부탁과 중간 진척 보존, 유효한 행동의 계속·중단·전환을 모델이 선택하는 기존 합의를 유지한다. 기존 실게임·외부 모델 시험 보류를 유지한다.

## 판단 제안 — 미확정

대상 목록 탐색에는 얕은 분류 트리가 유용하다. 현재 행동 유지, 눈앞의 구체적인 채집, 이미 정해진 목적지 이동과 기지 귀환은 직접 선택도 유지하도록 권고한다. 매 타격·걸음마다 트리를 처음부터 탐색하게 하면 반복 선택과 호출 지연이 생기므로, 최종 선택은 기존 연속 실행으로 연결한다.

예시 경로는 채집→관측·기억에 있는 자원 분류/품목→출처·장소→구체 실행, 이동→장소 종류→알고 있는 목적지→이동이다. 귀환할 기지가 하나면 직접 후보면 충분하며 여러 거점이 있으면 목적지 선택을 펼친다. 구체적인 분류와 순서는 현재 데이터와 모델 입력을 대조한 뒤 정한다.

실제 관측과 마지막 기억, 대상까지 거리·알려진 위험·접근 가능성, 현재 부탁·진척은 비교 판단에 유지한다. 트리 탐색이 목표 외 발견을 숨기거나 알려지지 않은 자원·장소를 공개하지 않도록 한다. 같은 실행은 직접 후보와 트리에서 동일한 실행·재검증 입구를 사용한다. 메뉴 뒤로·선택 취소는 몸 행동 중지나 부탁 취소와 구별한다.

이 문서는 구조 권고이며 트리 채택·개발 승인으로 취급하지 않는다.

## 후속 역할 경계 검토

[상위 LLM과 Decisions의 역할 판단](2026-11-07-채집이동귀환-역할판단.md)에서 기존 권고를 구체화했다. 위 예시의 품목·장소 트리는 모두 현장 모델에게 새 작업 목적을 정하게 한다는 뜻이 아니다. 상위 계획이 정한 값과 제약을 전달하고, 현장에 맡겨진 선택과 구체 실행을 좁히는 용도로 해석한다. 상위의 기억 조회·계획 수립 도구와 현장의 실행 선택 트리는 서로 다른 소비자를 위한 것이다. 이 후속 판단 역시 구현 승인 전 제안이다.
