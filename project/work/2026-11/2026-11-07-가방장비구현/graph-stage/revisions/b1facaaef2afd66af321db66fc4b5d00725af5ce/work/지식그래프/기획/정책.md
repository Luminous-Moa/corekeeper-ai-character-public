# 정책 — 합의된 결정

이 문서는 사용자가 정한 것만 정책으로 적는다. 결정의 원문은 세션 기록이다. 여기 적힌 줄은 그 요약 사본이다. 근거 줄의 따옴표 글은 원문에 그대로 있어야 한다. 그래프를 만들 때 도구가 이것을 확인한다.

규칙 한 줄은 "조건 / 주체 / 행위"로 쓴다.

새 결정이 생기면 먼저 세션 기록에 남긴다. 그다음 이 문서에 한 항목을 더한다. 이 문서에서 결정을 새로 만들지 않는다.

필드:
- 등급: 사용자 결정 / 사용자 원칙 / 사용자 방향
- 확정도: 확정 / 잠정 / 검토 중
- 종류: 처리(기능이 지킨다) / 원칙 / 범위 / 전제
