39: ## 검증과 전달
40:

42: - 대표 실행: 인벤토리 열기 → 분류 → 물품 → 뒤로 → 다른 물품 → 조작 → 필요한 인자 → 정상 실행 → 실제 결과 확인. 별도로 각 단계 전체 취소에서 물품·몸 동작·목표·원래 부탁이 유지되는지 확인한다.
43: - 8개·14개를 넘는 항목을 실제 생성·전달해 임의 누락이 없음을 확인한다. 여러 분류와 장비 변형·내구도가 있는 보유 물품, 빈 분류, 인벤토리 변경과 오래된 응답, 자기 상자 내용 관측, 일부 이동·가득 찬 상자, 수령 미확인, 호출 상한을 핵심 사례로 본다.
44: - 실제 모델에 보내는 메뉴 문구와 단계 전이 예시, 최종 실행 때의 후보·관측 연결을 산출물에 남긴다. 실제 외부 모델·실게임이 없으면 그 한계를 명시한다.
45: - 최종 변경판을 독립 검수하고 관련 오프라인 회귀·Unity 컴파일·설치 없는 SDK 후보 패키지를 준비한다. 공식 본/그래프 반영은 HEAD가 최종 결과를 보고 판단한다. 설치·게임·외부 모델 시험의 기존 보류는 유지한다.
