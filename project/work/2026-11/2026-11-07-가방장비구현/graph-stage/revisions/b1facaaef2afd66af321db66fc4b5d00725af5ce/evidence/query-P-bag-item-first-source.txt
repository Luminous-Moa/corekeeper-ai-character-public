11: ## 만들 결과
12: 
13: **인벤토리 → 실제 보유 물품이 있는 분류 → 그 분류의 보유 물품 → 가능한 조작 → 필요한 슬롯·대상·수량 → 실행**을 연결한다.
14: 
15: - 현재 메뉴의 자식 선택지만 현장 판단 모델에 전달한다. 트리 전체를 한 번에 보내 경로 문자열을 받는 방식 대신, 선택 경로와 현재 노드를 유지하는 실제 다단계 선택 상태를 사용한다. 이전으로 돌아가기와 전체 선택 취소가 실제 선택으로 작동해야 한다.
16: - 분류는 실제 게임의 아이템 유형·속성과 대응해 정한다. 물품이 있는 분류만 노출하며, 분류된 물품에는 현재 보유한 정확한 슬롯·종류·변형·상태·개수를 연결한다. 정적 DB 전체나 소유하지 않은 물품을 보유 목록처럼 노출하지 않는다.
17: - 가방·핫바·착용 중인 물품을 실제 위치와 함께 구별한다. 식별이 같은 개별 장비도 상태와 슬롯이 다르면 선택 가능하게 보존한다. 분류를 판별하지 못한 항목은 명시적으로 남겨 접근 불가가 되지 않게 한다.
18: - 현재 목표는 판단 맥락으로 유지하며 보유 목록을 목표 품목 하나로 숨기지 않는다. 다른 물품의 준비 조작도 고를 수 있고, 그 조작 성공과 현재 목표의 실제 충족은 구별한다.
19: - 한 물품을 고르면 그 위치와 현재 게임 조건에 맞는 착용·교체·해제·들기·보관·내려놓기·전달 등을 펼친다. 필요한 추가 인자만 다음 노드에서 선택한다. 모든 인자가 정해진 최종 실행 후보를 모델이 선택할 때 한 번 실행한다.
20: - 자기 상자에서 꺼내기는 기존 범위에서 유지한다. 자기 상자 선택·접근/열어보기 뒤 실제 관측한 내용의 분류와 물품을 고르는 경로로 연결한다. 열어보지 않은 상자의 내용을 추정해 보여주지 않는다.
21: - 각 단계에서 뒤로 가기와 선택 전체 취소를 제공한다. 뒤로는 부모 선택 단계로, 전체 취소는 일반 판단으로 돌아간다. 메뉴 조작 자체는 물품 이동·몸 동작 중단·현재 목표 완료·원래 부탁 취소를 수행하지 않는다.
22: - 물건을 버리는 동작은 기존 범위의 바닥 내려놓기(drop)로 연결한다. 영구 삭제(trash)는 별도 동작이며 이번에 추가하지 않는다.
