독립검수 최종 수용 후 커밋 685dde4d27dd91a782a14d8ae33fb576160fa578을 생성했다. 소스·기존 회귀·실제 입구 harness를 포함해 47개 파일, 추가873줄·삭제317줄이다. 작업트리는 clean이며 이후 root가 이 커밋을 ai-character에 fast-forward 통합했다. 설치본 배포는 수행하지 않았다.

## 실행 연결

관측으로 목표 조건이 충족되어도 AIGoals.CheckDone은 목표 수정번호·진척·현재 실행을 유지한다. CheckAfterBuild의 진척 후보 부족 역시 관측으로 남긴다. 모델이 finish_goal을 선택한 경우에 현재 단계를 끝낸다. stop_action은 관측한 실행 회차에 바인딩되며, 뒤늦은 답이 새 실행을 중지시키지 않도록 실제 AIActions.Stale에서 확인한다. request_plan은 상위 보고를 요청하고 현재 유효한 실행을 유지한다. 요청이 진행 중이면 현재 사실을 다음 보고에 전달하고 요청을 중복하지 않는다.

AIHostOrders.GoalEnded는 성공한 중간 목표를 이유로 사용자의 원래 부탁을 완료하지 않는다. 위쪽 LLM의 order=done 또는 orders의 명시 완료가 원래 부탁을 끝낸다. 사용자의 직접 중지는 기존 명령 경로로 실행한다.

AISkill.ObserveOnce는 실행 회차에 조건을 보존하고 재판단을 요청한다. AIBrain은 관측 수정번호와 마지막 요청의 수정번호를 비교해, 호출 중 생긴 관측이나 재시도 이유에 가려진 관측을 다음 입력으로 전달한다. 현재 실행의 관측 목록과 목표 조건은 현장 입력 및 상위 보고에서 읽을 수 있다.

## 종료와 실패 처리

- 호출 실패·키 없음·비용 상한은 새 호출을 제어하며 유효한 몸 동작·목표를 보존한다. 기존 예산은 유지한다.
- 응답 나이만으로 현장·상위 답을 버리는 분기를 제거했다. 목표 수정·쓰러짐·대상 소실·실행 회차 변경은 현재 사실에 따라 검사한다.
- recent failure 횟수, 탐험 실패 반경, 무피해 물체·농사 실패 위치·배치 실패 기록은 유효한 새 선택을 금지하는 근거로 쓰지 않는다. 대상별 실패 원인과 횟수는 후보 설명에 남긴다.
- 채굴·공격·파기·이동의 정책적 시간·무진척 제한을 관측으로 전환했다. 실제 child 실행 실패는 부모 결과에 원인과 진척을 전달하고 다음 행동을 모델에 맡긴다.
- 제작·상자 꺼내기·요리 요청의 반영이 늦으면 같은 UI 명령을 중복 발행하지 않고 pending 상태를 관측한다. 가방 변화가 뒤늦게 나타나면 기존 성공 판정으로 연결한다.
- 문·설치 자리 보정·물체 회수의 내부 상태 기계도 시간·반복 횟수로 정책 포기하지 않고 관측을 반환한다. 실제 대상·도구·입력 버퍼가 사라진 경우에는 실행 불가 결과를 전달한다.
- 모델에게 제시한 한 번 타격·짧은 이동·정해진 시간 기다리기·30초 따라가기 같은 명시 행동의 끝점은 유지했다.

Tools/execution-tests는 실제 AIGoals.cs·AISkill.cs·HostOrders/PlanRules를 링크하고 실제 Loop.Apply/ObserveExecution 메서드를 원문에서 추출해 실행한다. 게임 상태와 몸 입력은 fixture로 제공한다. 기반 11eb461에서는 10/10 강제 취소와 원래 갑옷 부탁 완료를 3/3 재현했다. 변경본은 수량 관측 후 현재 run·진척 유지, 다음 Tick, request_plan, stop_action, 새 동작 전환, 명시 finish_goal과 원래 부탁 유지, 상위 order=done, 무진척 관측, 관측 보존, 사용자 직접 중지를 확인했다.

새 Unity 실행·게임 설치·외부 모델 호출은 수행하지 않았다. 이 오프라인 실행은 실제 게임의 물리·네트워크 지연과 전체 coordinator를 구동한 검증이 아니다. 배포·기존 ai-character 병합은 부른 대화가 판단한다.

독립검수에서 명시 중단도 soft Stop으로 문닫기 tail을 기다리는 경합을 발견했다. stop_action, finish_goal, 위쪽 hold와 사용자 목표해제는 hard Stop으로 현재 실행 회차를 끝내며, 기존 EndSkill이 열린 문 부채와 중단 사실을 보존한다.

추가 독립검수에서 근접전 후보 묶음이 목표와 직접 관계없는 현재 행동의 계속하기를 숨기는 경로를 발견했다. Assembler.Select가 현재 실행을 위험 정보와 함께 복구하고 Finish의 개수 상한 뒤에도 모델이 고를 값을 보존한다. 실제 BodyCan 불가일 때 복구하지 않는 조건까지 3개 회귀를 추가했다. 위쪽 hold는 Goal.None 자기방어 중에도 몸을 중단한다.

명시 중단 직후 과거 예약 행동이 EndSkill의 완료 callback에서 되살아나는 경합도 수정했다. CancelPendingChoices가 중단 전에 예약·보류·다음 타격·prefetch와 요청 상태를 정리한다. Goal.None의 직접 사용자 중지도 같은 정리를 거친다. 실제 OnSkillEnded와 예약 상태까지 harness에 포함해 최신 중단 뒤 과거 선택이 부활하지 않는 조건, 평상시 정상 완료 뒤 예약 선택은 살아 있는 조건을 함께 확인했다.
