# A-1 실제 화면 상태 목록 (진행 중)

대상: 실행 중인 Core Keeper의 코어키퍼 AI 시험판. 부모가 전한 실행 기록 76563bf, 그래프 기준 e82eb87. 코드 읽기/빌드 확인 없이 실제 UI만 관측했다. PNG는 원본 증거이며 화면 우하단에 다른 앱의 업데이트 알림이 겹쳐 있다. 그 알림은 제품 화면요소가 아니다.

실행한 제품 명령은 /ai 하나뿐이다. on/off/goal 및 대상 지정 명령은 실행하지 않았다. UI 도구는 HTTP/IPC/상태코드/스트림을 캡처하지 않으므로 요청 증거는 키 입력과 화면 반응뿐이다. 네트워크 요청이나 로컬 처리 여부를 추정하지 않는다. accessibility는 게임 요소를 제공하지 않아 픽셀 관측했다.

시간/조작별 기계 기록: observations.json. 각 파일명은 본 폴더 기준이며 A-2는 기존 원본 PNG를 사용한다. A-3에는 이 문서/이미지 결과를 입력으로 주지 말고 시작 상황/목표/계정 상태만 전달한다.

조회 입구 확인은 /ai 하나에 한정되었다. 도움말의 … 뒤에 상태/가방/목표/기억 조회가 있는지는 화면에서 알 수 없었다. 대상 지정 초안은 실행 전 취소했다. 계정/월드/캐릭터/목표 변경, 설정 변경, 이동/전투/아이템 사용/저장/종료는 하지 않았다. 단 채팅 스크롤 시도에서 퀵슬롯 선택이 바뀌어 복원했고, 이 부수 효과는 제외하지 않고 기록했다.

## 관측된 응답 원문 전사

04-ai-help.png 화면의 줄바꿈을 합친 읽기 전사(픽셀 원본이 우선):

> Luminous: /ai
>
> AI: Claude 켜짐/들어와 있음/없음 · ChatGPT 꺼짐/들어와 있지 않음 · Gemini 꺼짐/들어와 있지 않음 · Grok 꺼짐/들어와 있지 않음 · 명령: /ai <개별> on|off|goal …

02-chat-open.png의 읽을 수 있는 후반 로그:

> AI 공격 완료: MushroomEnemy 처치 (체력 70→70) (3.9초)
>
> AI 물러나기 완료: 코어 스폰 자리 도착 (0.9초)
>
> AI 기다리기 완료: 2초 기다림 (2.0초)
>
> AI 자기 방어 끝: 위협 없음(25.6s, calls 56, hp 22->100, downs 1). 제자리에 쉽니다.

위 행동은 탐색 전에 있었던 로그다. 탐색 중 실행하거나 검증한 전투가 아니다. 원문의 작은 숫자/기호 전사는 후속 독립 이미지 검수 대상이다.

## A-1 완료 범위와 남은 한계

A-1 전체 상태 전수 탐색은 완료가 아니다. 이번 안전한 실제 화면 관측 결과는 월드/캐릭터, 채팅 입구, /ai 목록/짧은 도움말, 게임 메뉴 네 종류다. 생성/삭제/개별 켜기/끄기/목표 변경/전투/장비·가방 변화/오류·빈 상태는 관측하지 않았다. UI의 … 때문에 다른 읽기 명령을 발견하지 못했다. 게임 자체는 실시간 실행 중이므로 시간 경과에 따른 자연 변화는 있을 수 있다.
