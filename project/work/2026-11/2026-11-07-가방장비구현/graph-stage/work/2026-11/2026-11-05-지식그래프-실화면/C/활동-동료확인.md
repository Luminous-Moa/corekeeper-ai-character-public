# 동료가 와 있는지·무엇 하는지 알아보기

ID: CKAI-ACT-01

한 줄: 이미 실행 중인 월드에서 이름표·AI 목록·최근 메시지를 보고 동료의 존재와 행동을 부분적으로 확인한다.

문제는 가까운 캐릭터와 AI 메시지가 있지만 누가 AI이며 지금 무엇을 하는지 분명하지 않다는 것이다. 목표는 참여 상태와 최근 행동을 이해하는 것이며, 동료를 새로 참여시키는 기존 UA-01과는 다르다. UA-01의 참여 시작·저장·입장 성공 전체를 이 활동으로 완료 처리하지 않는다.

## 차례

시작: 게임 중인 호스트, 메뉴·입력 닫힘. 이동·전투·목표 변경 없이 현재 화면을 확인한다. 아래 기본 흐름은 A1 조작을 바탕으로 작성했고 독립 C3에서 Return → /ai → Return 조회를 재현했다.

| 단계 | 사용자 행동 | 화면요소 ID | 근거·얻는 것 |
|---|---|---|---|
| S01 | 주변 캐릭터 이름을 읽고 메시지는 보일 때만 읽는다 | CKAI-01#1-1, CKAI-02#2 | C3 초기에는 행동 메시지가 없었음. 이름만으로 AI 여부를 단정하지 않음 |
| S02 | Return으로 입력을 연 뒤 나타난 메시지를 읽고 `/ai`만 입력해 보낸다 | CKAI-02#2, CKAI-02#3 | A1 E02~04와 C3 재현. 입력→slash:ai 요청. A3는 이 명령을 스스로 발견하지 못함 |
| S03 | AI 목록에서 이름과 참여 상태를 읽는다 | CKAI-02#2-6, CKAI-02#2-7 | A1 E04와 C3. 에코와 응답 구별. 이름표 Claude와 참여 상태 일치. 응답이 사라지거나 가려지면 미확인으로 남김 |
| S04 | 최근 행동을 읽되 현재 목표·발화 주체의 불명확함을 구별한다 | CKAI-02#2, CKAI-02#2-2, CKAI-02#2-3, CKAI-02#2-4, CKAI-02#2-5 | A1은 탐색 전 로그, A3는 자연 발생 로그. 이 활동이 전투를 지시한 것이 아님 |
| S05 | 입력이 열려 있으면 Escape로 닫고, 이미 닫혔으면 추가 입력 없이 월드를 확인한다 | CKAI-02#3, CKAI-01#1, CKHUD-01#5 | C3에서 제출 후 자동으로 닫혀 Escape 불필요. 메뉴/입력 닫힘과 슬롯1 유지 |

관측된 우회 분기: 메뉴의 CKAI-03#10(접속자 목록), CKAI-03#10-1(Luminous 행), CKAI-03#10-2(Claude 행)를 보고 CKAI-03#7(플레이어 관리)를 선택한 뒤 CKAI-03#12의 SPACE 안내를 따라 들어가 CKAI-04#2-1(관리자), CKAI-04#3-1(차단 없음)을 읽었다. A3에서는 AI의 상태·목표를 찾지 못하고 Escape로 돌아왔다. 목적에 맞지 않았던 경로를 감추지 않되 기본 추천 흐름으로 만들지 않는다.

관측된 막힘·복원: A1/A3가 CKAI-02#2 위에서 휠을 돌렸을 때 로그 대신 CKHUD-01#5-10이 선택되었다. Escape 후 1 키로 CKHUD-01#5-1을 복원했다. 이 부수 효과를 반복하도록 기본 흐름에 넣지 않는다. `/ai Claude` 초안은 CKAI-02#3에만 나타났고 취소되어 기능 실행 근거가 아니다.

끝: 동료의 존재·최근 행동을 부분적으로 이해하거나 미확인 내용을 기록하고 월드 화면으로 돌아온다. 현재 지속 목표와 발화자 연결이 불명확하면 그 상태로 끝낸다. ‘없음’은 코드상 목표 텍스트 자리라는 해석을 연결 문서에 두며 사용자에게 자기 방어도 없다는 뜻으로 설명하지 않는다.

다음 활동 ID: 없음. 기존 UA-02/UA-04/UA-07은 가능한 다른 목적이지만 이번 실행으로 이어지지 않았다. 자동 `유저 활동→유저 활동` 또는 navigate 간선을 만들지 않는다.

## 실제 확인과 기획의 차이

A1의 `/ai` 실행 성공과 A3의 명령 발견 실패는 동시에 참이다. 실행 가능한 문법이 있다는 사실이 발견 가능한 UI라는 뜻은 아니다. 화면에서 최근 메시지를 읽었다는 사실이 목표·현재 기술·자기 방어 상태를 모두 얻었다는 뜻도 아니다. C3에서 조회 실행과 참여 상태 확인은 성공했지만 메시지 시각·동료 귀속·현재 목표는 확인하지 못했다. C4-반영.md에서 이 범위를 반영한다.
