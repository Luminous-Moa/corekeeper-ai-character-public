# 독립 재기획 그래프 제작 결과

사용자 진입점은 [README](README.md)다. 큰 그림 Mermaid, 다음 기획 질문, 철검 부탁의 설명용 흐름, 참고 경계를 제공한다. [관계목록](관계목록.md)은 각 항목의 상태·내용·원문 위치·나가는 관계를 보여 준다.

## 범위

- 재기획 32노드: 최근 합의 6문서에서 방향 합의·제안·설명용 사례·미정 질문을 구분했다.
- 참고 11노드: 현행 기억 평가, 행동 누락 조사, 행동 전체추출, 기지 안전 4a 보류, 과거 장 요약·교훈·협력 멘션·실플레이 계획, 자연어 명령 과거 설계, 기존 그래프·능력 색인.
- 전체 43노드·55관계·14원문. 관계는 원문 합의/제안/사례와 정리자가 붙인 해석을 구분했다.
- 기존 그래프·기획·제품 코드·context.md를 수정하지 않았다. 이번 작업에서 쓴 파일은 모두 이 폴더 안에 있다. 게임·외부 LLM을 실행하지 않았다.

## 실제 소비 흐름 확인

`node verify.mjs`의 최종 결과는 [verification.json](verification.json)에 있다. 모든 8개 조회 명령의 종료 코드는 0이며, 핵심 경험에서 43개 노드 모두에 관계를 따라 도달한다.

대표 질문 ‘친구 같은 경험을 만들려면 목표·계획·기억·행동이 어떻게 이어지고 무엇이 미정인가?’에 대해 다음 경로를 실제 조회했다.

1. P.experience → P.life → P.hierarchy → P.cycle → P.execution: 경험에서 실제 작업 실행까지 연결.
2. P.experience → P.life → P.hierarchy → P.cycle → P.agency → P.confidence → Q.memory-rules: 계획·기억 연결과 신뢰도 세부 미정 확인.
3. P.experience → P.life → P.hierarchy → P.cycle → P.execution → R.missing: 새 방향에서 현행 공백 조사로 넘어갈 때 ‘참고’ 경계와 기록 당시 기준판 확인.
4. `source P.agency`, `source R.missing`으로 계획 주도권 합의 원문과 행동 누락 조사 원문을 열었다.

`check`는 끝점/중복 ID, 모든 원문 앵커, 출처 해시, 재기획 근거의 최근 6문서 제한, 참고→재기획 정책 관계 금지, JSON/관계목록 재생성 일치를 확인했다. 같은 입력으로 다시 계산한 결과와 저장물이 일치한다. 단순 앵커 검사는 의미 정확성을 보증하지 않으므로 독립 원문 대조가 별도로 필요하다.

## 한계

최근 재기획과 관련 참고를 연결한 결과다. 과거 모든 대화·할 일·코드를 전수 수록한 결과는 아니다. 참고의 구현 상태는 해당 문서의 기준판을 따르며 이번에 제품 동작을 다시 검증한 것이 아니다. ‘모든 게임 행동 전수 발견’, ‘4a 실게임/병합 완료’, ‘기억 활용 플레이 완성’으로 확대하지 않는다. 기존 후속 아이디어는 새 정책으로 승계하거나 폐기하지 않는다.

이 문서는 제작·기계 검증 결과다. 독립 검수 결과와 최종 수용은 상위 대화에서 기록한다.
