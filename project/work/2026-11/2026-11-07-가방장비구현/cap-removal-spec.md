# 후보 개수 상한 제거 상세 범위

근거는 [트리 합의](tree-agreement.md)와 분류·상한 조사다. 가방 메뉴 파일과 Loop/설정은 다른 담당이 소유하며, 이 작업은 world 후보 생성과 Core 조립의 숫자 기반 누락만 제거한다.

- 최종 조립의 비전투14/선택적 전투 상한을 제거한다. 기존 public Finish/LimitFor 호출 형식은 유지하되 positive limit 인자도 후보를 자르지 않는다. 정렬·실행 가능성·실패 사실 표시·wait와 value 부여는 보존한다.
- 관측된 적·벽·뿌리·부술 물체·드롭·동료·기억 광석·탐험 대상, 상자 보관/준비·음식·야생 씨앗·횃불과 결과별 설치/둘레 후보의 숫자 cut을 제거한다.
- 목표 탐색 대상을 몇 개만 시도하고 중단하던 외부 타깃 횟수는 후보 열거 cut으로 구별한다. 개별 길찾기 내부의 노드/시간 예산·frontier job의 탐색 guard는 변경하지 않는다.
- HEAD 후속 판단에 따라 close-fight의 목표 계속하기 ONE quota도 제거한다. 그 목표측 선택의 progress/Doable·자동으로 들어오는 줍기 제외·BodyCan 자격과 전투 우선 순서는 유지한다.
- 관측 시야·소유권·실행 가능 조건·동일 action key 중복 제거·광맥 묶음/결과별 대표는 보존한다. 행동 한 번에 다루는 물리 batch, 장소/보고 텍스트 요약, 기억·로그 보관, call/cost 상한은 변경하지 않는다. Core AIBaseEdgeCore.Options의 MaxOptions4는 현장 선택 목록과 다른 상위/명령 둘레 설계안 소비자이므로 이번에 변경하지 않는다.
- 기억 광석 조회는 후보 경로에서 max<=0을 제한 없음으로 사용하며 상위 보고의 명시 max 요약 호출은 유지한다.
- 과거 ASM fixture 자체는 보존한다. 재생검사는 과거 cut14 결과를 새 전체 목록의 앞부분/기존 상대 순서와 비교하는 역사 어댑터로 구분하고, 별도 현재 계약 검사로 14개가 넘는 모든 입력이 Finish 결과와 값에 남는지 검증한다.

소유 파일은 부모가 지정한 world/Core 후보 생성 파일 및 관련 회귀 검사다. 코드 커밋·Unity·설치·공식 그래프는 이 작업에서 수행하지 않는다.
