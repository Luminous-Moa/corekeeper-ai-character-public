# 실제 메뉴 자식 입력 예시

실제 Candidates에서 받은 문구를 최소 World 시험에서 기록했다. cN은 시험이 순서대로 붙였으며 실제 BuildJson/Loop 연결은 상위 검증을 따른다. 실제 외부 모델 호출이나 게임 관측이 아니다. 목록을 요약하거나 자르지 않았다.
