# Jev 대안: 독립 비교 벤치마크 확인

확인 기준: 2026-11-03. 공개 원자료만 열람했고 모델 설치·추론·유료 API 실행은 하지 않았다. 이 문서는 벤치 결과의 판단이며 모델별 최신 제공 조건·라이선스 확정은 별도 공식자료 조사와 합쳐야 한다.

**결론: 최신 비교에 포함된 Jev 1.14보다 높은 텍스트 결정 정확도 평균을 보인 모델은 있다. 가장 직접적인 후보는 Perplexity Decider V1.2이며, 속도까지 중시하면 Decider Flash V1.2다. 그러나 Core Keeper의 장기 행동·전투·탐험을 더 잘한다는 근거는 확보되지 않았다.**

## 1. 가장 직접적인 최신 비교: System One Bench

2026-11-02 round 10까지 갱신된 제삼자 벤치다. 동일한 state/questions를 사용한 3,250개 사례, 4,850개 결정, 영어·프랑스어·아랍어 16개 데이터셋이다. 아래 지수는 **데이터셋별 정확도를 똑같은 비중으로 평균한 값×100**이다. 전체 문항 정답률이나 별도 지능 점수가 아니다. [프로토콜과 라운드 설명](https://github.com/alilibx/system-one-bench)

다음 수치는 [results.json](https://github.com/alilibx/system-one-bench/blob/main/results.json)을 직접 읽고 지수·1,000회 비용을 재계산했다. 지연은 GPU 연산 시간이 아니라 OpenRouter Decisions API의 클라이언트 왕복이다.

| 모델 | 지수 | pooled ECE↓ | p50 / p95 ms | 1,000 API 호출 USD |
|---|---:|---:|---:|---:|
| Jev 1.14 | 79.29 | 5.96% | 136.2 / 174.7 | 0.02788 |
| Decider V1.2 | **84.63** | **0.66%** | 177.5 / 374.1 | **0.00652** |
| Decider Flash V1.2 | 81.94 | 1.83% | **104.0 / 176.8** | **0.00465** |
| Microsoft-Decision-1 | 82.02 | 2.77% | 240.2 / 321.2 | 0.01046 |
| Mercury Decide | 82.38 | 13.07% | 275.5 / 820.3 | 무료 경로 사용 |
| GPT-6 Luna Decisions | 75.95 | 9.78% | 214.7 / 581.6 | 약 0.0403 |
| d1-ultra | 82.91 | 1.02% | 167.5 / 290.5 | 0.01034 |
| Drex Max | 84.09 | 6.17% | 277.4 / 789.5 | 0.02138 |

비용은 기록된 API usage 비용이다. Jev/Decider의 3,250회 합계는 $0.0906/$0.0212이고 보고된 입력 토큰도 2,157,160/1,058,085로 다르다. 동일 문장을 받더라도 공급자별 토큰 계산·과금량이 같지는 않다. Mercury의 0달러를 유료 정가로 해석하면 안 된다. Luna 비용은 성공 호출 3,248회 기준이다. [원결과](https://github.com/alilibx/system-one-bench/blob/main/results.json)

해석 조건:

- Jev 1.14는 10월 15일 실행, Decider V1.2는 10월 25일 실행이다. 후자의 서버에서 Jev 대조 실행은 p50 122ms였고 기존 표는 136ms였다. 저자는 약 10% 범위의 비교로 설명하며 꼬리 지연은 더 흔들렸다고 명시했다. 모든 시점·하드웨어를 고정한 실험은 아니다.
- 0.66%는 모든 결정을 합친 ECE다. 데이터셋마다 과신·저신뢰가 상쇄될 수 있고 Decider V1.2의 개별 데이터셋 ECE는 1.5~8.5%다. 실제 게임의 신뢰도 임계값으로 바로 사용할 수 없다.
- Jev 1.13→1.14 지수 변화는 79.0→79.3으로 반복 실행 잡음 범위라는 저자 판단이다. 과거 Jev 1.13에 대한 승리를 최신 버전 승리로 자동 승계하지 않았다.
- 최신 GLiDE 지수도 84.1이지만 별도 Fastino API이며 비교 가능한 지연을 게시하지 않았다. 코드 Apache-2.0, 결과 CC BY 4.0, 데이터는 원 데이터셋 라이선스다. 공개 데이터 고정은 재현성에 도움을 주지만 학습 오염 부재를 증명하지 않는다. [라운드·측정·라이선스 설명](https://github.com/alilibx/system-one-bench)

## 2. 게임 행동을 판단할 때 더 중요한 논문

[Evaluating and Benchmarking the System One Model Jev, v2](https://arxiv.org/html/2609.37647v2)는 2026-10-29 개정본이며 **jev-1.13.0**을 평가했다. 37개 데이터셋 346,009회 요청에서 Jev가 Qwen3.8-27B를 27개 데이터셋에서 앞섰지만, 연속 행동에서는 결과가 달랐다.

| 환경 | Jev 1.13 성공률 | Qwen3.8-27B 성공률 | 표본 |
|---|---:|---:|---:|
| ALFWorld | 35.1% | **54.5%** | 134 에피소드 |
| TextWorld | 42.2% | 51.1% | 90 게임; 신뢰구간 겹침 |
| BabyAI-Text | **20.8%** | 16.8% | 250 미션 |

동일 요청·선택지를 사용해도 Jev는 무효 행동을 반복하고 이미 방문한 막다른 길을 다시 찾았다. FrozenLake에서는 세 모델 모두 미끄러짐 결과를 제대로 추론하지 못했다. Blackjack 최적 행동 선택은 Jev 90.0%, Qwen 84.9%로 반대였다. 단일 선택 확률의 좋은 보정이 연속 행동의 보정으로 이어지지 않았다. [논문 §5, 표9](https://arxiv.org/html/2609.37647v2)

독립 학술 연구이며 코드·원응답을 공개했다. 다만 요청당 한 번 실행했고 실행 간 변동은 미측정이다. 공개 데이터의 문답쌍 암기를 배제하지 못하며, 최신 Jev 1.14 및 Decider V1.2를 평가하지 않았다. **추론: 게임에서는 모델 교체와 별개로 실행기가 방문 이력·실패 행동·가능한 결과를 구조화해야 한다.** [한계와 논의](https://arxiv.org/html/2609.37647v2)

## 3. 작은 합성 테스트의 보조 근거: akitaonrails

[독립 저장소](https://github.com/akitaonrails/jev-docs-benchmarks)는 영어/PT-BR 84개 원형을 번역·조건 변형한 합성 규칙 테스트다. 168개 compact 문항에서 로컬 Perplexity Decider 1.1 27B 167개, Jev 및 Microsoft 각각 164개, OpenAI Decisions 152개가 정답이다. 로컬 Decision 3.0도 Perplexity와 같은 예측을 냈다. 3개 문항 차이로 일반적 우월성을 주장하지 않는다. Jev는 1.13 계열 과거 실행이다.

[Microsoft 추가 분석](https://github.com/akitaonrails/jev-docs-benchmarks/blob/main/benchmark/reports/microsoft-comparison-v2/analysis.md)에서 Microsoft−Jev 차이의 family-bootstrap 95% 구간은 −3~+3%p다. compact 호출 비용은 $0.00645/$0.01916 per 1,000회지만 토큰량×당시 단가의 사용량 평가이며 전체 청구서 대조는 아니다. p50은 422/255ms다. 로컬 Perplexity는 약 49GiB 가중치와 ROCm fallback 환경에서 p50 1,547ms였고 운영비는 미측정이다.

AI 작성 라벨에 독립 인간 판정이 없고 번역·변형은 상관된 표본이다. task/language 셀은 12개 원형뿐이다. 높은 분류 정확도에도 알려진 무작위 사건의 Boolean 확률이 틀렸다. OpenAI가 그 특정 확률 probe에는 더 강했다. 따라서 분류 정확도, 확률 추론, 서비스 비용의 우열을 합치면 안 된다. [한계](https://github.com/akitaonrails/jev-docs-benchmarks#methodology-and-limitations)

## 4. 실제 연속 동작의 다른 근거: AIM-Decision

[AIMultiple 원실험](https://aimultiple.com/decision-models)은 브라우저 50개 과제를 같은 jev-ultrafast 실행기에서 평가한다. 본문 수치로 Jev 1.13은 18개, Kev-27B는 40개, SubQ Snap은 41개, Gemini 3.8 Flash는 43개, GPT-6 Astra는 47개를 완료했다. 분류 선두 decider-12b는 브라우저에서는 16개였다. **이는 분류 순위를 행동 에이전트 순위로 바꿀 수 없다는 추가 근거다.**

텍스트 입력은 공통 Mercury 텍스트 도우미가 수행하므로 결정 모델 단독 성능도 아니다. API 오류는 실패로 포함하며 실제 페이지 종료 상태를 검사한다. 공개 과제는 10개이고 40개는 후속 평가용 비공개다. 로컬 비용은 A100을 가득 활용한 처리량에서 추산하고 준비·로딩·유휴시간을 제외한다. 일부 Kev 실행은 느린 참조 커널이라 최적 GPU 추론 비교가 아니다. API 비용도 실제 OpenRouter usage, 정가 환산, 임대 추산이 섞여 있다. [방법·비용](https://aimultiple.com/decision-models)

최신 페이지에는 Jev 1.14와 Decider V1.2도 있지만 이 조사에서는 동적 표의 원 CSV ZIP 열람이 차단되어 두 모델의 브라우저 성공률을 확정하지 않았다. 본문에 없는 값을 추정하지 않았다.

## 참고 검증: 84문항 Fathir 벤치의 과대해석 방지

[Fathir 원실험](https://www.fathir.live/blog/system-one-decision-models)은 Jev 1.13 84/84, Kev-4B 72/84, Laya 60/84다. Jev API 355ms와 로컬 GB10의 Kev 74ms/Laya 16ms는 네트워크 포함 여부가 다른 실측이다. 저자 한 명이 만든 영어 84문항이며 다수가 먼저 Jev로 개발됐다. 저자도 Jev의 100%를 일반 성능으로 읽지 말라고 명시한다. 후행 디코딩 변경으로 얻은 Kev 79/84는 사후 분석이다. 여기서 GPT-6 Luna 일반 API의 7회 probe를 OpenAI Decisions API 성능으로 인용하면 안 된다.

## 이번 프로젝트에 적용할 판단

1. **범용 텍스트 결정 대체 후보:** Decider V1.2를 Jev 1.14와 대조할 근거가 가장 직접적이다. 이 벤치에서 정확도·비용은 유리하고 지연은 더 길다. Flash는 평균 정확도와 p50 모두 유리하지만 같은 게임에서의 우위는 미검증이다.
2. **다른 후보:** Microsoft는 비용과 typed-decisions에 강한 근거가 있다. Mercury는 평균 정확도가 높아도 과신과 꼬리 지연이 크다. OpenAI Decisions가 모든 면에서 더 좋다는 자료는 없고 제공 경로·확률 질문 종류에 따라 결과가 달라진다.
3. **게임 검증에서 분리할 항목:** 행동 선택 정확도, 임무 성공률, 무효 행동 반복률, 사망·자원 손실, p50/p95 응답 시간, 성공 임무당 비용, 보류/상위 추론 호출률. 같은 관측·행동 후보·실행기를 고정한 실제 Core Keeper 평가가 최종 기준이다.
4. **라이선스:** 벤치 코드의 공개 라이선스는 비교 대상 모델 가중치나 서비스의 상업 이용 허가가 아니다. 모델별 공식 라이선스·서비스 약관을 별도로 확인해야 한다.
