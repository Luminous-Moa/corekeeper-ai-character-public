# 지식그래프 활용 지침 배치

다운로드 폴더의 최근 Markdown 아홉 파일을 `C:/Dev/_ref/head-agent-core/graph/build/`로 옮겼다. 기존 그래프 제작 지침 두 파일이 있던 위치이며, 문서끼리 파일명으로 연결되어 있어 아홉 파일을 같은 폴더에 두었다. 이 위치 선택은 로컬 저장소 구조와 문서 링크에 따른 배치이며 다운로드 서버의 배포 경로를 그대로 복제한 것은 아니다.

- [지침 목차](C:/Dev/_ref/head-agent-core/graph/build/README.md): 시작·그래프 제작·화면 조각·기획·디자인·개발기획·코더·QA 안내.
- 코어키퍼 [그래프 README](../../지식그래프/README.md)와 [사용법](../../지식그래프/제품그래프-사용법.md)에서 공통 활용 지침을 연결했다.
- 원본 아홉 파일의 본문·파일명을 그대로 보존했고 이동 전후 SHA-256을 비교했다. 다운로드 폴더에서는 이동 대상 아홉 파일이 없어졌다.
- 기존 정의·제작 지침 두 파일은 줄바꿈 외에 내용이 같았다. 교체 전 파일을 `previous/`에 보존했다. [이동 목록](moves.json)에 원본·목적지·해시가 있다.
- 설치된 플러그인 캐시, 스킬 등록, 자동 주입 설정은 변경하지 않았다. 공통 문서를 한 위치에 두고 기존 프로젝트 진입점에서 찾아갈 수 있게 연결한 작업이다.
