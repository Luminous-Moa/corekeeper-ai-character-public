# 기억이 실제 플레이에 쓰이는지 확인할 시험

2026-11-07에 나중에 다시 생각하기 위해 남긴 계획 초안. 시험 시점과 검색 담당 모델은 열어 둔다.

**확인할 질문**은 한 캐릭터가 직접 발견한 자원을 나중에 기억해 내고, 그 기억을 이용해 사용자의 부탁을 완수하는가이다. [검색 경로 시뮬레이션](2026-11-07-검색경로시뮬레이션/batch-100/report.md)은 합성 장면에서 첫 행동 선택까지 확인했다. [기존 플레이 이력](2026-11-07-플레이판단분포/report.md)에서는 기억한 위치가 행동 후보에 이미 들어가는 경우도 확인했다.

1. 캐릭터가 철광맥을 발견하고 위치를 관측한 뒤, 광맥이 보이지 않는 곳으로 이동한다. 같은 캐릭터에게 “철 좀 구해 줘”라고 부탁한다.
2. 발견 당시 저장된 기억, 부탁 당시 제공된 관찰과 행동 후보, 모델이 직접 요청한 조회, 선택한 목적지, 실제 이동과 철 확보를 연결해서 본다. 이미 제공된 기억만으로 돌아간 경우도 기억 사용으로 센다. 우연히 다시 발견한 경우에는 기억의 효과를 단정하지 않는다.
3. 같은 광맥이 고갈된 것을 캐릭터가 확인한 뒤 다시 부탁한다. 최신 관측을 반영해 다른 곳을 찾는지, 예전 위치로 되돌아가는지 본다.

**판단 기준**은 기억이 목적지나 행동을 바꿔 부탁의 완료에 기여했는지다. 조회 횟수는 기억이 전달된 경로를 설명하는 자료로 쓴다. 진행이 막히면 기억을 찾지 못한 것인지, 기억한 곳을 골랐지만 이동·채굴을 실행하지 못한 것인지 기록한다.
