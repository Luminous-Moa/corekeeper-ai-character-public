# 기본 행동 정비 순서

사용자는 코드가 AI의 선택을 강제 취소하는 부분을 제거하고 부족한 기본 선택지를 추가하도록 지시했다. 구현 범위가 커서 먼저 선택지 추가 순서를 논의한다. 아래는 착수 순서 제안이며 구현 완료 기록은 아니다.

## 공통 선행 작업

AI가 명시적으로 행동을 중단·전환할 수 있게 하고, 수량 충족·정해진 시간 경과·진척 없음·판단 호출 실패를 사실로 보고해 계속 또는 취소를 판단하게 한다. 원래 부탁과 중간 단계 진척을 보존한다. 이미 끝난 타격이나 사라진 대상에 대한 결과는 실제 상태로 전달하고, 현재 실행 가능한 유효한 선택을 코드가 자체 기준으로 취소하는 분기를 없앤다. 사용자의 직접 중지와 AI가 새로 선택한 중단·전환은 실행한다. 이 검토는 모든 행동 모듈과 예약·지연 응답 경로를 포함한다.

## 추가 순서 제안

1. **채집·이동·귀환 선택 확대**. 실제로 본 자원과 정확한 게임 규칙에서 채집 가능한 품목을 결정한다. 기존 벽 채굴과 줍기를 재사용하고 철 등 고정 허용 목록 밖 품목을 실제 목표 지정과 실행까지 연결한다. 목표 외 광맥을 가치 있는 후보로 제공하고, 이동·추가 채집·기록 후 계속 이동·귀환을 비교하게 한다. 일반 귀환의 현장 제공과 발견의 관심 이유·재방문 단서는 새 연결이 필요하다. 완료는 철광맥 발견·기억·채집·목표량 이후 추가 채집 또는 귀환의 한 연속 흐름으로 판단한다.
2. **가방과 장비의 직접 조작**. 가진 도구·근접무기·방어구를 골라 들고 착용하는 선택, 필요한 물건의 보관·꺼내기·전달을 연결한다. 대상 슬롯·수량·전후 상태를 확인한다. 공격 코드가 모델이 고른 무기를 유지하도록 연결한다. 각 동작은 독립적으로 완결해 순차 적용한다.
3. **전투 수단 확대**. 원거리 무기 선택·조준·발사·거리 조절을 실제 몸 입력과 결과 관측까지 연결한다. 기존 근접·후퇴와 함께 선택할 수 있게 한다.
4. **시설을 이용하는 생활 행동**. 제작·수리·강화·농사·요리·낚시·거래 등을 검수된 그래프의 정확한 대상·역할·조건·결과에 맞춰 차례로 연결한다. 장비 보강 귀환과 원작업 재개는 2~4단계의 동작을 계획으로 연결해 검증한다.

각 묶음에서 그래프의 게임 행동을 모델 선택→몸 실행→실제 결과 확인에 대조한다. 현재 가능한 연결을 재사용하고 각 묶음의 대표 실제 흐름으로 완료를 확인한다. 일부 그래프 수용 기록과 최종 통합 검수는 계속 진행 중이므로 채택 시점의 검수된 근거를 고정한다.
