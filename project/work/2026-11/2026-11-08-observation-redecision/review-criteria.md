# 관측·재판단 독립 검수 기준

2026-11-08. 기반43c3817. 이 문서는 사용자가 승인한 근본 사용 흐름 수정의 수용 기준이다. 검수자는 제품 소스를 직접 수정하지 않고 발견사항을 구현 담당에게 전달한다.

## 최신 사용자 승인

모델이 완료를 선택해도 스크립트가 실제 완료를 확인하지 못했다면 미완료 사실을 판단모델에 알리고 다시 호출한다. 이 승인은 기존 finish_goal의 무검증 단계 진행을 수정하는 근거다. 모델은 계속·중단·전환·재계획을 선택하며, 스크립트는 실제 실행과 달성 사실을 검증한다. 원래 부탁은 상위가 관리한다.

## 필수 수용 기준

### 완료 선택과 실제 결과

- 구리0/5 상태에서 finish_goal을 골라도 다음 제작 단계로 넘어가지 않는다.
- 현재 단계의 부족량·아직 확인되지 않은 사실·실행 상태를 명시해 다시 판단받는다.
- 미완료 finish 시 현재 유효한 실행과 원래 부탁·남은 계획을 보존한다.
- 실제 완료가 확인되면 finish_goal을 통해 다음 단계로 진행할 수 있다.
- 상태 변화·새 목표·늦게 도착한 응답에서도 완료 검증은 현재 목표와 실행 회차에 맞는다.
- 완료 선언, 스크립트가 검증한 결과, 상위의 원래 부탁 완료가 보고·경험 기록에서 구별된다.

### 미해결 상태의 재판단

- pending 관측 후 continue를 골라도 조용한 비전투 상태에서 갱신된 재판단이 다시 발생한다.
- 요청·준비 중 발생한 새 사실은 다음 유효한 판단에 전달된다.
- 같은 pending은 매 프레임 새 호출을 만들지 않는다. 기존 최소 간격·분당·월 예산·실패 재시도 조건을 지킨다.
- 비용·호출 한도에 걸린 경우 현 상태와 재개 조건이 유지되며 같은 관측의 반복 로그·재요청이 폭주하지 않는다.
- 목표 교체·명시 중지·스킬 종료 뒤 옛 대기 관측이 현재 작업을 다시 깨우거나 종료하지 않는다.
- 주기만 돌고 내용이 동일한 상태를 반복하는 데 그치지 않고, 각 주기에서 실제 수령·실행·방향 필요 사실을 다시 관측한다.

### 통로 갈림길

- 다음 방향을 고르지 않은 갈림길에서 continue의 실제 효과와 아직 필요한 선택이 분명하다.
- continue 후에도 방향 판단 필요 상태가 남아 재판단으로 이어진다.
- 갈래를 스크립트가 임의 선택하지 않는다.
- 중간 공통 통로를 실제로 걸을 수 있는 continue는 유지된다.
- 예약 방향의 유효성·현재 실행 회차·갈림길 토큰을 검증한다.
- 실기에서 계속하기만 반복하며 같은 좌표에 정체되는 현상이 해소됐는지 확인한다.

### 전달 결과의 귀속

- 바닥 entity가 이미 사라진 경우에도 수령자 상태를 실제 측정한다. 미측정과 증가0을 구별한다.
- 출발 감소만으로 지정 수령 성공을 확정하지 않는다.
- 성공 증거는 이번 요청·정확한 물품·지정 수령자에 귀속돼야 한다.
- 다른 플레이어 수령, 같은 물품 동시 이동, 수령 직후 착용·상태 변화가 잘못된 성공으로 이어지지 않는다.
- 관측이 불확실한 이미 송신된 drop을 자동 재전송하지 않는다.
- 대상 소실·인벤토리 읽기 실패·부분 수량·요청 처리와 관측 순서 변화에서도 수량과 상태가 일관된다.
- 한 부위 수령 확인 후 다음 부위 계획으로 실제 진행한다.

### 관측의 목표·실행 귀속

- 직전 WoodMiningPick1/1 완료 관측을 새 CopperOre0/5의 현재 완료 사실로 전달하지 않는다.
- 새 목표에서도 기존 몸 실행이 남을 수 있으므로 그 사실은 이전 실행의 소속을 명시해 전달한다.
- 입력·후보·결과·상위 보고에서 현재 목표rev, 실행run, 관측 시점·수정번호를 연결해 대조할 수 있다.
- stale 응답은 새 목표·실행을 잘못 종료하거나 옛 관측으로 덮어쓰지 않는다.

## 검증 방법

생산 코드의 실제 입구를 호출하는 재현을 우선한다. 별도로 복제한 간이 상태 머신만 통과한 결과는 생산 연결 증거가 부족하다.

| 재현 | 필요한 확인 |
|---|---|
| fake clock의 조용한 pending | first observation→continue→시간 진행→새 재관측/판단, 동시 요청1개와 예산 준수 |
| 구리0/5·직전1/1 | finish 선택 뒤 현재 목표 유지, 실제 부족 사실 재입력, 뒤 단계 미진입 |
| 빠른 줍기·floorNull | 실제 지정 수령 검증 또는 정직한 미확인, 중복 지급0 |
| 갈림길 공통 구간 끝 | continue 뒤 구체 방향 선택 기회 재발생, 자동 갈래 선택0 |
| 목표 전환·응답 지연 | 옛 관측/결정이 새 목표 완료를 오판하지 않음 |
| 수령 완료 뒤 다음 부위 | 완료 사실→finish→다음부위 실행→실제 수령을 끝까지 확인 |

최종 실기에는 실제 전체 하위 입력과 후보 설명·key, 선택 응답, 목표/실행 회차, 수령 증거를 보존한다. 정상 HTTP와 이동만으로 사용자 부탁 수행의 완료를 판정하지 않는다. 설치·게임 조작은 실기 담당의 승인 범위에서 수행하며 독립 검수자는 원문 증거를 대조한다.

## 결과 기록

검수 결과에는 후보 커밋, 변경 파일, 실제 실행한 검사, 발견사항의 심각도와 근거, 수정 후 재검수 결과, 아직 검증하지 못한 범위를 적는다. 실제 수령 및 다음 단계 진행이 미확인이라면 최종 수용은 보류한다.
