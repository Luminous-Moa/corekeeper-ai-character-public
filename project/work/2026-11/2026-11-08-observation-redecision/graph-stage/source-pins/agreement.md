# 실행 관측과 재판단 흐름 수정

사용자는 모델이 완료를 선택했더라도 실제 완료되지 않은 사실을 스크립트가 알리고 판단모델을 다시 호출하는 흐름으로 수정하도록 요청했다.

목표는 장비 전달과 통로 대기에서 미확인·무진척 상태가 장시간 방치되지 않고, 현재 사실에 근거한 다음 선택으로 이어지는 것이다. 이미 전달된 장비를 다시 지급하지 않도록 수령 관측을 정확히 한다.

## 구현 기준

- 대기와 실행, 관측 미확인과 확인된 완료를 구별한다. 정체가 계속되면 갱신된 관측으로 기존 호출 예산 안에서 재판단한다.
- 관측은 목표·단계·대상·실행 회차에 연결하고, 이전 목표의 성공 사실이 새 목표로 넘어가지 않게 한다.
- 모델의 완료 선택과 실제 관측이 맞지 않으면 현재 사실을 명시해 재판단하며 원래 부탁과 미완료 의무를 보존한다.
- 계속·중단·전환은 AI가 선택한다. 미완료를 알고 중단하는 의사와 실제 완료 사실을 구별한다.
- Give 수령 확인을 바닥 엔터티 포착에만 의존하지 않도록 수정한다. 출발 가방 감소만으로 성공을 단정하지 않는다.
- 통로 방향 선택 대기에서는 계속하기가 어떤 진전을 만들 수 있는지 정확히 알리고 구체적 다음 선택으로 연결한다.
