## 실행 관측

몸 Tick 시작에 현재 조건 표식을 비우고 실제 ObserveOnce 호출이 있으면 다시 세운다. 다음 Brain Tick이 직전 몸 Tick의 상태를 사용한다. 프레임 시간으로 사실의 유효성을 추측하지 않는다. 조건이 사라진 뒤에는 과거 사실을 반복 요청하지 않는다.

관측은 원래 목표 세대·목표 이름·실행 번호를 가진다. 목표가 교체되면 전역 최근 관측과 미소비 깨움은 새 목표에 맞춰 초기화한다. 계속 실행 중인 이전 행동의 사실은 원래 목표를 표시해 남긴다. 상위 보고와 하위 요청에 같은 소속을 표시한다.

## 전달 확인

수령자 전체 가방·착용 수량은 바닥 엔터티 포착 여부와 관계없이 측정한다. 읽지 못한 값은 미관측으로 표현한다. 자기 DropItem의 일시적인 dropper 표식을 pickup 전에 관측하고, 같은 바닥 엔터티가 지정 수령자에게 전달되는 상태를 인벤토리 소비 전에 관측한다. 이후 출발 감소·바닥 감소·지정 수령자 증가를 맞춰 완료를 판단한다.

관측 시스템은 게임 입력과 인벤토리를 변경하지 않는다. 동일 물품을 다른 사람이 떨어뜨리는 경우에는 sender 표식으로 구분한다. 송신한 DropItem을 반복 전송하지 않는다. 정확한 게임 시스템 순서와 동적 등록은 Unity 및 실게임에서 별도로 확인한다.
