## 재판단과 실제 진척의 구별

t541.5 갈림길 끝에서 방향 미선택이라는 관측이 하위로 전달됐고, t542.0 모델이 북쪽 갈래를 골랐다. t542.1부터 (24,-2)에서 실제 이동했고 t542.8에는 (24,3)에 도달했다. 이후 새 갈림길에서도 판단이 계속 발생했다.

새 갈림길·통로 끝 관측으로 다음 판단에 도달하는 흐름을 확인했다. 이 구간에서 새5초 갱신을 나타내는 `대기 조건 재관측` 문구는0건이다. 다만 이번 조용한 갈림길에서는 모델이 곧바로 방향을 골랐다. 계속하기 뒤에도 동일한 조용한 대기 상태가 남아서5초 뒤 깨는 조합은 실게임에서 직접 관측되지 않았다. t690.7의 continue는 한 칸 걷는 중이었고, 다음 방향 선택은 t693.92에 있었다. 생산 어댑터의 조용한 pending 검증과 실기 관측 범위를 구별한다.

상위가 탐험을 재설정한 뒤 하위 입력은 기존 실행에 이전 목표·세대·run 표시를 붙였다. 이 귀속 표시가 정확해도 길 선택이 이미 지나온 곳을 반복할 수 있다는 점은 현재 좌표 기록에 남는다. 구현 측 코드 분석에서는 지속되는 travel-memory가 통행 가능성만 보존하고, 방문 간선 집합 `_walkedEdges`는 TravelSkill 실행마다 새로 만들어지는 것을 확인했다. 다른 실행에서 이미 방문하거나 막힘을 확인한 갈래의 결과가 새 후보에 전달되지 않는 경로가 현재 반복 선택과 맞물린다. 상위 action_replan은 방향 선택 때 `AIExpedition.Choosing`이 현재 실행 설명을 갱신한 뒤 미검토 현장 기회 집합의 변화에서 발생하는 경로가 확인됐다. 상세 소스 판정은 코드 분석 보고서와 함께 읽어야 한다.

## 시험 조건과 현재 상태

이 실행은 사용자 원본 aiui1106과 다른 전용 ai2다. 초기 core 주변 적을 시험 명령으로 정리했고, 장비3개를 AI에게 준비했으며 t332.1 호스트를 시험 이동으로 재합류시켰다. 이후 탐험 지역에서는 새 적이 관측됐다. 바지 지연 구간에도 전투 종료 및 AI 체력102→78 기록이 있다. 전체 기간을 조용한 비전투 조건으로 간주하지 않는다.

시험 담당의 이동 입력 없이 t556.6 호스트가 북쪽으로 걷는 기록이 나타났고 UI에서 위치 변화가 확인돼 입력을 중단했다. t746.1 사용자가 `/ai stop`을 실행했다. 이 명령 뒤 보존 로그 끝까지 하위 SEND가 없고 상위 요청 취소·auto off·목표 해제·현재 통로 실행 취소가 기록됐다. 11시45분 읽기 확인에서 게임은 실행 중이었다. 정상 종료와 새 백업 복원은 사용자 확인 대기 상태다.
