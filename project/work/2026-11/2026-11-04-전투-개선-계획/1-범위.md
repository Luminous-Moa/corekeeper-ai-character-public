# 전투 개선 계획 범위

- 요청: 현재 전투 진단을 바탕으로 개선 계획만 세운다.
- 목표: 모델이 관측 가능한 적의 전조와 실제 무기 상태를 보고 짧은 전술 행동을 선택해 실행하며, 싸움·이탈 뒤 원래 목표 또는 준비 목표로 이어 가는 흐름을 설계한다.
- 산출물: 구현 순서, 각 단계의 결과와 검증 기준, 의존성·불확실성·범위 경계를 갖춘 제안 계획.
- 조건: 이번에는 제품 코드·설정·게임 상태 변경, 빌드, 실게임, 모델 시험 호출을 하지 않는다. 전술 선택은 모델이 하며 빠른 판단·실제 동작 속도·사람이 볼 수 있는 정보 원칙을 유지한다. 성공은 상황에 맞는 선택과 실행이며 무사망을 목표로 삼지 않는다.
- 순서: 사용자가 정한 현재 작업 마무리 → 리팩토링 → 다음 기능 순서를 유지한다. 전투 구현은 그 뒤의 후보이며 이번 계획 작성은 착수 승인이나 리팩토링 실행을 뜻하지 않는다.
- 근거: 직전 전투 현황 진단, 전투 컨트롤 todo, 개발 지식그래프 정책, 최신 작업 세션 기록.
