# 전투 개선 계획 독립 검토

2026-11-04. 범위·개선 계획·직전 상세 진단/결론·관련 전투 정책만 대조했다. 제품 소스 재조사, 게임 실행, 빌드, 모델 호출, 설정 변경, 계획 직접 수정은 하지 않았다.

## 판정

**수정본은 계획 제안으로 수용 가능하며 진행을 막는 문제는 없다.** 초안에서 요청한 비동기 실행 계약과 실제 속도/경계 처리 보강을 수정 구간 재독으로 확인했다. 관측 부족·큰 행동·근접 전용·위험한 코어 복귀·부적절한 번복·피해 학습 문제는 단계 0~5에 모두 연결된다. 실제 사망 집계 누락도 단계 0에서 처리한다. 근접 제어와 이탈을 한 완료 묶음으로 둔 점은 유효하다.

## 초안 보강 요청과 반영 확인

1. **단계 2의 비동기 응답과 경계 대기를 작은 상태/시험표로 명시할 것.** 현재 대상·무기·행동 식별 검사와 완료 뒤 계속하기 금지는 있으나, 짧은 동작이 응답보다 먼저 끝났을 때의 나머지 처리 계약은 실행자가 정해야 한다. 최소한 ① 실행 중 응답과 경계 대기, ② 대기 중 새 선택/계속 응답 도착, ③ 자연 완료 뒤 도착한 계속/새 행동 응답, ④ 같은 종류 행동을 다시 시작한 뒤 이전 응답 도착, ⑤ 대상 소실·파손·지형 변화, ⑥ 응답 지연/실패 후 다음 요청을 다룬다. 후보의 안정된 키와 개별 실행 회차 식별을 구별하고, 각 경우의 적용·폐기·대기 취소·재판단 및 그동안의 몸 상태를 정해야 한다. 현재 정책의 지연 시 유효 행동 계속/멈춤을 유지하며 완료한 한 번 공격을 자동 반복해서는 안 된다. 이 표를 대표 E2E에도 넣으면 단순 성공 장면만으로 비동기 경계를 통과시키는 일을 막는다.
   - 근거: 상세 진단 「실제 판단 속도와 전환 규칙」의 대기 전환 적용 후 늦은 계속 응답 폐기, 기존 정상 stale 검사. 정책 `cand.motion-boundary`, `pol.reflex-minimal-now`. 기존 검사를 현존 버그로 다시 고치라는 뜻은 아니다.
   - **반영 확인:** 단계 2에 고유 실행 번호·한 입력 소유자·중복 적용 금지·새 선택/대기 요청 처리 및 비동기 5조건 시험표가 추가됐다. 계획 수준의 주요 결손은 해소됐다. 구현 때 대기 중 같은 행동/계속 선택이 오면 대기 전환을 취소하는 기존 계약도 이 표에 따라 확인한다.

2. **단계 0·2에 실제 속도 읽기 실패와 기존 강제 전환 경로를 명시할 것.** ‘실제 속도와 취소 가능한 시점 확인’은 방향이 맞지만, 정책은 현재 게임 값 우선 → 못 읽으면 해당 캐릭터 자신의 최근 휘두르기 간격 관찰값이라는 순서를 정한다. 이 fallback과 장비/버프 변경 시 갱신을 적고, 능력치 합산으로 별도 속도를 만들어 쓰지 않도록 한다. 또한 진단에 있는 기존 ‘경계 2초 대기 후 적용’·긴급 전환 경로가 짧은 공격의 취소 불가능 구간을 어떻게 다룰지 확인 항목과 실기 기준에 넣어야 한다. 총 지연에는 이 대기 시간을 포함하고, 정책상 긴급 전환과 게임 입력이 실제 수용되는 시점을 구분한다.
   - 근거: 정책 `pol.motion-real-speed`, 상세 진단 「실제 판단 속도와 전환 규칙」. 계획의 총 지연 p95 검증은 적절하나, 경계가 오지 않는 경우의 계약은 별도 보강이 필요하다.
   - **반영 확인:** 단계 2에 현재 게임 타이머→해당 캐릭터 관찰값→모름 순서, 별도 능력치 합산 금지, 기존 2초 강제 적용을 그대로 승계하지 않는다는 계약과 실패 시험이 추가됐다. 주요 결손은 해소됐다. 단계 0의 정상 무기 비교/파손 무기 별도 시험도 확인했다.

추가로 요청한 **회복을 섞은 순HP 변화·여러 타격·막타·관측 간격과 실제 발동 간격의 구분**도 단계 1에 반영된 것을 확인했다. 사건을 분리할 수 없으면 순변화/모름으로 남긴다. 새 정밀 추정 체계를 만들지 않고 진단의 잔여 항목을 닫는 범위다.

## 수용 가능한 한계와 보존된 조건

- 전조 필드·가시성, 피해 사건 귀속, 석궁 입력/자원, 수리는 미확정 조사 항목으로 남겼다. 기존 진단의 참고 타입이나 석궁 소지를 곧 실행 능력으로 가정하지 않는다.
- 짧은 이동·공격·발사 조합은 모델이 고른다. 자동 회피, 위험 후보의 전술적 강제 배제, 응답의 안전 행동 덮어쓰기를 채택하지 않는다. 빠른 호출과 비용 상한도 유지한다.
- 판단 적합성·실행 일치가 중심이고 무사망·임의 승률이 성공 기준이 아니다. 같은 조건 반복, 네 AI, 동료 피해, 목표 재개, 독립 검수까지 있어 E2E 방향은 충분하다. 버전별 5회는 초기 제안이며 효과가 불명확하면 그대로 보고하는 한계도 명시됐다.
- 첫 대상과 첫 원거리 무기를 좁혔으므로 모든 적/무기·수리 구현을 완료 조건으로 삼지 않아도 된다. 세 마리 밖 공격대상 등의 상세 확장은 단계 5의 입력·후보 적합성 검토에서 필요성을 판단해도 된다.
- 현재 열린 작업 마무리 → 리팩토링 → 다음 기능 순서를 보존한다. 이 문서는 계획 검토이며 구현 착수·새 정책·사용자 소유 선택의 확정이 아니다.
