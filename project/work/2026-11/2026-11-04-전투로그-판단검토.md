# 전투 로그 판단 검토

## 범위와 기준
- 요청: 최근 AI 전투 로그를 확인해 판단모델의 판단에 문제가 있었는지 평가한다.
- 당시 모델에 전달된 관측과 후보, 선택, 실제 실행 결과를 연결해 본다. 모델 선택의 문제와 관측·후보 설계·실행 문제를 구분한다.
- 패배나 전환 횟수만으로 오류라고 판단하지 않는다. 새 사실 없는 번복, 동일 위협의 반복 긴급 처리, 잘못되거나 누락된 정보가 유발한 선택을 살핀다.
- 이번 작업의 산출물은 근거가 있는 평가이며 게임 코드·설정 변경이나 새 실게임 실행은 포함하지 않는다.

## 조사 결과
완료. 상세 근거와 고정 로그: [상세 분석](2026-11-04-전투로그-판단검토/analysis.md).

- 최신 swarm4로 식별되는 실행의 Claude 완료 전투 #17~#19를 조사했다. 247회 요청 중 입력 전문이 남은 5건은 타당·합리적 4건, 모델과 후보 문제를 분리할 수 없는 1건이었다. 모델 단독의 명백한 오판은 이 5건에서 확정하지 못했으며 전체 판단 정상이라는 뜻은 아니다.
- 확실한 문제는 이전 거리 벌리기의 계속하기 응답이 공격으로 바뀐 뒤 도착했을 때, 실제로는 공격이 계속된 실행 불일치다.
- 판단 일관성이 의심되는 공격·대기·회피의 짧은 번복과, 벌린 거리를 코어 복귀로 다시 좁혀 Brute와 붙은 사례도 있다. 다만 해당 요청의 입력 전문이 없어 모델 단독 문제와 후보·시차 문제를 분리할 수 없다.
- 코드·설정·게임 상태는 변경하지 않았다. 기록만으로 확인 가능한 범위의 평가를 마쳤다.
