# 유저저니 — 화면 기반 추정

- ID: `CKAI-JOURNEY-01`
- 사용자/상황: 이미 실행 중인 Core Keeper 월드의 호스트. AI 동료가 와 있는지와 무엇을 하는지 알아보려 한다.
- 관련 활동: `CKAI-ACT-01` 한 가지. 아래 단계는 서로 다른 활동이 아니다.

| 단계 ID | 단계 | 원하는 것 | 관측 또는 한계 |
|---|---|---|---|
| CKAI-JOURNEY-01-S01 | 실행 중인 월드에서 동료의 단서를 마주침 | 함께 있는 대상 찾기 | A1·A3에서 Claude 이름표와 AI 메시지가 보임. 제품을 처음 알게 된 외부 경로·설치·동료 초대 과정은 미관측 |
| CKAI-JOURNEY-01-S02 | 이름과 접속 여부를 확인함 | 이 대상이 누구인지 알아보기 | A3는 접속자 목록과 플레이어 관리로 이동. 관리 화면은 AI 설명을 주지 못함 |
| CKAI-JOURNEY-01-S03 | 최근 메시지와 조회 안내를 찾아봄 | 현재 활동을 이해하기 | A3는 채팅 로그를 읽지만 명령을 발견하지 못함. 별도 A1 경로는 `/ai` 목록 응답 확인 |
| CKAI-JOURNEY-01-S04 | 일부만 이해하고 탐색을 멈춤 | 불필요한 변경 없이 월드로 돌아오기 | A3는 최근 전투·회피·대기 메시지를 이해했으나 지속 목표와 정확한 AI 식별은 확정하지 못함. 메뉴·입력 닫힘과 퀵슬롯 복원 확인 |
| CKAI-JOURNEY-01-S05 | 다시 확인할 계기가 생김 | 달라진 동료 행동을 알아보기 | 재방문 자체는 미관측. 메시지나 동료 행동의 변화가 재확인의 계기가 될 수 있다는 추정만 남김 |

떠난 곳은 제품 종료가 아니라 **동료 확인 활동의 종료**다. 게임은 계속 실행됐다. 제품 이탈·재접속·장기 이용·재방문 빈도는 알 수 없으므로 저니 사실로 채우지 않는다.
