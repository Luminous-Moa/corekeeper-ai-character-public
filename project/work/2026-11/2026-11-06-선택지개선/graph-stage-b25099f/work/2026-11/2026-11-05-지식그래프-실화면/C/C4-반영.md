# C-3 반영 및 제품 판단 목록

C-3 입력은 C3-input.md 한 파일이었고 별도 컨텍스트가 실제 수행했다. 결과 정본은 ../C3/flow-check.md와 PNG 5장이다. Return → /ai → Return으로 조회 및 Claude 이름표·참여 상태 일치 확인에 성공했다. 행동 종류는 부분 이해했지만 동료 귀속·메시지 시각·현재 목표는 미확인이다. 메뉴/입력 닫힘과 슬롯1을 유지했다.

반영: 활동 S01은 메시지가 보일 때만 읽게 하고, S02는 채팅을 연 뒤 메시지를 읽도록 고쳤다. S03은 응답이 빨리 사라지거나 포인터로 가려질 수 있음을 명시했다. S05는 전송 후 자동으로 닫혔으면 Escape를 추가로 누르지 않게 했다. 실제 전달한 C3-input.md는 실행 근거이므로 수정하지 않았다. C3는 명령 발견 가능성을 검증한 것이 아니다. 아래 제품 판단 목록을 유지한다.

| ID | 발견 | 필요한 제품 판단 | 현재 처리 |
|---|---|---|---|
| CKAI-C-U01 | A3는 빈 채팅에서 조회 명령을 찾지 못함 | 명령 입구·도움말을 어디에 어떻게 드러낼지 | 제품 수정 없음; `/ai`를 아는 흐름과 발견 가능성을 구별 |
| CKAI-C-U02 | 행동 메시지에 발화자 연결이 불명확, 상태의 ‘없음’에 필드명 없음 | 동료 식별·목표·현재 행동을 어떻게 구분할지 | 상태 의미의 코드 근거만 문서화, 새 표시 정책 없음 |
| CKAI-C-U03 | 큰 로그·빠른 교체·내부 용어·깨져 보이는 글자·생략 안내 | 사용자용 메시지 크기/용어/상세 보기/보존 방식을 개선할지 | 관측 조건을 보존, 현재 결함 원인 단정 안 함 |
| CKAI-C-U04 | 채팅 위 휠이 로그 대신 퀵슬롯 선택에 영향을 줌 | 게임 경계 안에서 기록 탐색 또는 입력 전달을 바꿀지 | 실제 부수 효과 기록, 재현 흐름에서 휠 사용 제외 |
| CKAI-C-U05 | 가방/기억 명령이 순수 조회로 보장되지 않음 | 조회와 행동 변경을 분리하거나 부수 효과를 알릴지 | 이번에 inv/mem 미실행. 코드 사실과 향후 판단만 구별 |

이 목록은 승인된 제품 변경·새 정책·기존 U.*의 폐기가 아니다. 사용자에게 확인 요청을 자동 발송하지 않는다. 게임 본체 메뉴/렌더러, 미관측 목표·가방·기억, 모든 멤버/상태 변형과 실행판 전체 추출은 사실 확인의 남은 경계다.
