# 개발 지식그래프 실화면 후속 결과

기존 개편에서 미뤘던 실제 게임 화면 관측과 그래프 연결을 보완했다. 컴퓨터 유즈로 실행 중인 Core Keeper를 탐색하고, 처음 온 사용자 관점과 문서대로 따라가는 관점을 분리해 실제 사용을 확인했다.

## 실제 결과

- 월드·채팅·게임 메뉴·플레이어 관리와 공통 HUD를 5개 화면, 57개 요소로 문서화했다. 원본 14장에 위치 매칭본을 붙였다. 별도 C3 재현 원본 5장은 독립 실행 근거로 보존한다.
- 대표 활동은 동료의 존재·최근 행동 확인이다. 실제 `/ai` 조회에서 Claude의 켜짐·접속 상태와 이름표가 일치했다. 활동→입력/응답 요소→기존 `slash:ai`→처리 코드→설정 파일 데이터→원문 조회를 연결했다.
- 안내 없이 탐색한 사용자는 명령 발견과 현재 목표 확인에 막혔다. 명령을 안내받은 흐름에서는 상태 조회가 성공했지만, `AI` 접두어만으로 행동 주체나 현재 목표를 확정할 수 없었다. 성공과 한계를 구별했다.
- 기존 개발 그래프 진입점·사용법을 갱신했다. 이전 정책·결정·인용·HTTP 증거와 코드 기준판은 보존했다. 관측에서 추정한 표시 규칙은 사용자 확정 정책으로 승격하지 않았다.

## 검증

통합 담당은 실제 질문 4개, 비대표 원본 표본, 동일 입력 재생성, 기존 노드·간선·인용 보존 및 진입점 7개 검사를 통과했다. 최종 `check`의 구조 오류와 낡은 입력은 0이다. 상세 실행 증거는 [D 보고서](D/report.md)와 그 연결 파일에 있다.

최종 [독립 검수](Review/independent-review.md)는 이번 실화면 후속 범위에 합격으로 판정했다. 독립 진입점 실행·비대표 표본 원문·기존 근거 보존 대조를 통과했고 구조 오류·낡은 입력은 0이었다. 시각 검수에서 채팅 부모·자식 상자 경계가 겹쳐 식별이 어려운 점을 찾아 여백을 주었다. 원래 좌표에도 하위 요소는 포함되어 있었으며, 데이터 누락으로 기록하지 않는다.

## 보존 조건과 남은 범위

제품 코드·설치·월드/캐릭터 저장·전투 시험 정리·context.md는 수정하지 않았다. 탐색 중 휠이 퀵슬롯을 바꾸는 부수 효과는 원래 1번으로 복원했다. 모든 UI 탐색 종료 시 메뉴와 입력을 닫았다.

실행 설치 소스는 76563bf와 30/30 정규화 해시가 일치하고 그래프 코드 원본은 e82eb87이다. 이 비교는 디스크 소스 증거이며 메모리에서 로드된 코드의 동일성이나 전체 전투판 검증은 아니다.

전체 상태 전수, 목표·가방·기억 명령, 저장/재입장, 외부 모델·기억검색 성공은 미확인이다. `inv/가방`은 현재 행동을 끊을 수 있고 `mem/기억`은 지연 초기화 시 저장·복사가 가능해 이번 운영 보존 범위에서 실행하지 않았다. 게임 본체 렌더와 플레이어 관리 내부 코드는 기존 추출 경계로 남긴다. [제품 판단 목록](C/README.md)은 발견 사항이며 제품 변경 승인으로 취급하지 않는다.
