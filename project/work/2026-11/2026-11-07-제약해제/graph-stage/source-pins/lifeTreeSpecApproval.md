# 첫 단위 구현 명세 승인

[명세](03-spec.md)의 첫 통합 단위를 승인한다. 공통 탐색과 네 갈래의 실제 선택·실행·결과가 연결되며, 수량별 후보 열거·탐색에 따른 행동 중단·현재 목표 진척 오염을 방지하는 기준은 합의와 맞는다. 기반은 의존 검수에서 확인한 1fc89b9로 고정한다.

개별 작업 수량은 상위 count로 지정하고, 명시 요청을 농사6칸/요리5짝 추천 묶음의 전체상한으로 취급하지 않는다. 실제 실행/확보한 만큼만 결과를 보고한다. 익숙한 대상은 루트 탐색 없이 같은 입구로 실행하며, 화면 밖 상태·아직 없는 능력을 현재 실행 가능하다고 표시하지 않는다.

코더는 명세의 대표 생산코드 파이프라인·필요 회귀·Unity 컴파일을 수행한다. 어댑터 검증의 범위를 실제 게임/모델의 검증으로 확대하지 않는다. 결과를 독립 검수한 뒤 공식 반영·미확인·후속 단위를 구분해 보고한다. 설치·실게임 보류는 유지한다. 명세와 고정판의 충돌 또는 새 제품 규칙이 필요한 경우 그 사실과 선택을 반환한다.
