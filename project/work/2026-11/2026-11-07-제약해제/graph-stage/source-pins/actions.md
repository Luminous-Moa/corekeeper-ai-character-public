# 게임 자체의 대상과 행위부터 분석하는 방향

## 합의한 행동 정의

행동은 플레이 주체가 의도를 가지고 게임 상태를 바꾸려는 시도다. 어떤 대상에 무엇을 하는가로 정의한다.

**행동 = 대상 × 행위**

예를 들면 바위 × 캐기, 무기 × 장착하기다. 버튼 누르기 같은 입력, 바위를 캐기 같은 행동, 광석을 모아 장비 만들기 같은 목표·활동은 구분한다. 실패하더라도 행동을 시도한 것으로 본다.

## 분석 순서

1. 모드의 현재 코드·선택지에 앞서 코어키퍼 게임 자체의 그래프를 만든다.
2. 코어키퍼의 모든 대상을 가져와 정리한다.
3. 게임에서 가능한 행위를 전부 정의한다.
4. 대상과 행위를 조합해 가능한 행동을 확인하고, 각 조합이 가능한 조건을 정리한다. 모든 조합이 가능하다고 가정하지 않는다.
5. 이렇게 정리한 게임의 행동 체계를 기준으로, 모드가 AI에게 제공하는 능력과 비교해 빠진 행동을 찾는다.

행동의 조건과 결과를 분석하려면 먼저 행동 단위가 정해져야 한다. 모드가 이미 제공하는 행동만으로 게임의 행동 목록을 한정하지 않는 것이 이 순서의 취지다.

## 이번 기록의 범위

이 문서는 사용자와 합의한 분석 방향이다. 대상·행위의 실제 전수 수집, 게임 그래프 제작, 모드 능력 비교는 아직 수행하지 않았다. 자료 출처, 수집 방법, 대상·행위의 상세 분류와 그래프 스키마는 아직 정하지 않았다. 이번 요청은 두 합의를 저장하는 것이며 분석 작업 착수 요청은 아니다.
