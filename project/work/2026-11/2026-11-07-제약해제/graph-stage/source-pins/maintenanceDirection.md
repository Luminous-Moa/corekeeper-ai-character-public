# 다음 단위 개발 방향 승인

이미 조사한 [개발 방향](../2026-11/2026-11-07-생활트리구현/next/01-direction.md)의 일반 수리→레벨 업그레이드를 승인한다. 첫 단위는 c4a0f5e로 수용되었으므로 문서의 당시 후보/검증 중 표현은 그때의 상태로 읽는다.

정상 단일 수리의 요청·실제 내구도/비용, 대장간 입력→업그레이드→회수의 한 흐름을 기존 LifeEntries/ExactCandidate/AIActions/ILifeResult에 연결한다. 트리는 조회 구조이고 실행 순서를 강제하는 루틴으로 만들지 않는다. 일괄 수리·최대 강화·새 소비 정책은 범위 밖이다.

다음 명세는 새 목표/작업 형식과 정확한 장비·시설 신원, 정상 요청 payload·거리/비용 조회·부분 결과·재진입/중복 방지·실제 회수와 대표 검증을 정한다. 기존 작업을 다시 조사해 계획을 새로 만드는 대신 이미 확인한 소비자/게임 근거와 현재 생산 인터페이스를 재사용한다. 첫 단계 그래프 검수는 반복하지 않는다.
