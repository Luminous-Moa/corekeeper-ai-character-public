# 최신 생활 트리와 가방·장비 트리 통합

## 새로 확인한 사실

공식 ai-character가 `c4a0f5e38016c79567f880bbaea5e56e0eeae347`로 갱신됐다. 이 판은 가방 실행 부품 `1fc89b9` 뒤에 생활 트리 `24c61c2`와 작업 수량·준비 재검증 `c4a0f5e`를 포함한다. 공식 G/P/L도 이 판에 맞춰 변경됐으므로, 가방·장비 격리판 `741532f`나 그 그래프를 그대로 공식에 덮어쓸 수 없다.

`741532f`의 코드·오프라인 연결 흐름·독립 검수·Unity·설치 없는 SDK 패키지 증거는 유효한 중간 결과로 보존한다. 해당 결과는 새 통합판의 검증을 대신하지 않는다. 현재 본 저장소와 설치를 이 대화에서 변경하지 않았다.

## 유지할 합의

- [가방·장비 트리 합의](tree-agreement.md): 인벤토리 → 실제 보유 분류 → 보유 물품 → 조작 → 필요한 인자 → 실행. 뒤로·전체 선택 취소, 임의 후보 개수 상한/페이지 제거, 원래 부탁과 유효 몸 동작 유지.
- [생활 트리 합의](../2026-11-07-생활트리구현/00-agreement.md): 작업 → 대상/재료 → 시설/구역 → 수량으로 필요한 수준만 탐색하고, AI가 정확한 대상·수량을 이미 알면 바로 실행할 수 있다. 탐색이 몸 동작을 취소하지 않고 작업 수량·조건·실제 결과를 구별한다.
- 두 트리는 서로 다른 승인된 소비자다. 생활의 완전히 지정된 실행을 무조건 인벤토리 루트부터 다시 고르게 하거나, 인벤토리의 분류·보유 물품 선택을 생활 준비 루틴으로 대신하지 않는다.
- 작업에 지정된 수량과 현장 후보 목록의 개수 상한은 서로 다르다. 요청 수량·권한·실행 가능성·실제 관측과 기존 호출 예산은 유지하면서, 현장 선택지 개수를 자르는 상한은 제거한다.

## 서로 다른 탐색 계약에 대한 통합 판단

생활의 [승인 명세](../2026-11-07-생활트리구현/03-spec.md)는 페이지를 오가며 모든 항목에 접근하는 커서와, 읽기 전용 탐색 중 held/queued 보존을 명시한다. 가방 트리 합의는 분류·보유 물품을 임의로 자르거나 페이지로 나누지 않고, 새 가방 선택보다 과거인 응답의 적용 권한을 만료하는 기준이다. 다음은 이 차이를 적용하는 HEAD의 통합 판단이며 새로운 사용자 원문 인용이 아니다.

- 가방 분류·물품·조작 목록은 무상한·무페이지로 유지한다. 전체 기본 후보14개 제한과 후보를 영구히 누락하던 생성 단계 숫자 자르기는 제거한다.
- 별도 승인된 생활 메뉴의 손실 없는 페이지 탐색은 보존한다. 이를 제거한 상한이라고 보고하지 않으며, 생활 항목도 결국 모두 접근 가능해야 한다.
- 생활의 읽기 전용 탐색 중 대기 선택 보존과 가방의 새 선택 권한 처리를 각 소비자에 맞게 보존한다. 어느 쪽도 유효한 현재 몸 동작·원래 부탁을 취소하지 않는다.
- 메뉴를 바꿀 때 다른 메뉴의 커서·토큰만 닫거나 무효화하고, 생활 진척·수량/Runs·현재 목표를 지우지 않는다. 이미 만료한 선택 응답을 복구하지 않는다.
- 일반 평면 가방 후보는 숨기되, 생활 트리에서 이미 대상·수량을 고른 명시 실행 binding은 보존한다. 두 승인된 흐름의 식별과 설명을 섞지 않는다.

## 맡긴 결과와 판단 기준

최신 공식 코드와 두 트리의 변경을 격리 통합 브랜치에서 연결한다. 기존 검수 판의 Git 참조·패키지·기록을 보존하고 작업 폴더/캐시를 재사용할 때도 환경 수정과 제품 코드를 구분한다. 본/공식 그래프/설치/게임은 최종 판단 전 변경하지 않는다.

- 공유 Apply/Compose/Resolve, action kind 식별, 메뉴 소유권·전환, 오래된 응답과 미리 받은 선택의 적용 권한을 함께 확인한다.
- 한 메뉴 탐색과 뒤로·취소가 다른 작업의 현재 몸 동작·원래 부탁·수량 기록을 지우지 않아야 한다. 인벤토리와 생활 양쪽의 실제 선택 흐름이 살아 있어야 한다.
- 기존 자기 자원·시야·공개 범위와 실제 슬롯/수량/수령 관측을 유지한다. 다른 승인 내용과 실제로 충돌하는 정책이 있으면 정확한 근거와 함께 HEAD로 돌려보낸다.
- 관련 생활 회귀, 인벤토리 메뉴·연결 흐름, 공통 선택권한·프로토콜·컴파일을 새 통합 소스에 맞춰 실행한다. 고정 통합판의 독립 검수·지식그래프 재핀·Unity 및 설치 없는 SDK 패키지를 준비한다.
- 공식 반영 시 최신 공식 입력이 다시 바뀌지 않았는지 읽고 확인한다. 다른 대화의 기획·코드·기록을 과거 사본으로 되돌리지 않는다.

이 통합은 승인된 두 결과를 함께 보존하기 위한 실행 전략이며 새 생활 기능·전투/채집 전체 트리·공유 자원 정책·비용 상한 확대를 승인한 것이 아니다. 실게임·외부 모델·설치 보류는 유지한다.
