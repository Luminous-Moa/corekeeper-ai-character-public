# 완료 판단 기준

사용자는 임의 제약 전반 해제에 더해 사용자 부탁·계획 길이·장거리 이동·지원 행동도 명시적으로 포함했다. 완료는 수치상 검사삭제가 아니라 상위 입력 → 실제 선택 후보 → 정상 몸 동작/게임 요청 → 실제 결과 관측까지 그 수치/종류 제한이 다시 생기지 않는 것으로 판단한다. 생산코드의 대표 오프라인 흐름과 독립 검수를 근거로 삼고 실게임 미확인은 분명히 남긴다.

- 원정 채집200, 제작10초과, 배치30초과가 임의로 거절되거나 총량이 작은 묶음으로 바뀌지 않는다.
- 계획10단계초과와 열린 지시4개이상이 소실 없이 보존된다. 큰 작업의 진척·원래 부탁 완료 구분은 유지된다.
- 생활6번째 항목과 전체 분류, 임의 대표화로 사라지던 통로/목표 밖 자원이 후보에 도달한다. None/Free와 combat의 후보 억압을 해제 범위에서 점검한다.
- 본 것/보유품/본 제작대 레시피·재료로 지식 공개를 여는 정책은 유지하고, 채집4종 별도 제한을 그 지식/실행 조건과 연결한다.
- 기존 기지반경/농장3~9와 장거리박스260은 미합의 공간정책으로 전체 작업을 막지 않는다. 프레임당 계산예산은 길없음·작업불가와 구별한다.
- 감사에서 제한한 도구/무기 및 특정 적 전용 제어는 실제 실행경로를 넓혀 선택·동작·관측을 검증한다. 미구현이라고 단순 제외하거나 fake capability만 노출해서 완료 처리하지 않는다.
- 인벤토리·장소·상자·사건·대화·기억/검색 내용은 임의 top-N/글자상한 때문에 사라지지 않는다. 사용자에게 허용되지 않은 지식으로 정보량을 늘리지는 않는다.
- 기존 사용자 예산·구독보호·동시요청/중복실행 방지·정상 슬롯/충돌/재료 게임규칙은 별도 의미로 보존한다.

특정 항목이 미완료면 전체 해제 완료로 보고하지 않는다. 구현 보고의 coverage는 감사01/02 항목마다 실제 변경·기존해제·유지사유·미완료를 구분한다. 대표 새 행동과 전체 목표량에서 특히 한 번의 실행 묶음과 총작업의 차이를 검증한다.
