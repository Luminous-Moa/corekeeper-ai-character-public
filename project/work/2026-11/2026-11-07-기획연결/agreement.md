# 독립 재기획 그래프의 작업 기준

사용자 요청: 코어키퍼 작업 세션에 연결하고, 여러 대화에 흩어진 재기획 내용을 지식그래프처럼 관계로 모은다.

- 문제: 플레이 경험, 목표·역할·제약, LLM 판단과 기억, 게임 행동과 모드 제공 능력에 관한 합의가 여러 기록으로 분산되어 있다.
- 결과: 재기획 전용 독립 그래프에서 새 기획 개념·결정·미결을 관계로 탐색하고 원문 근거로 돌아갈 수 있게 한다. 전체 그림에서 세부로 내려갈 수 있는 읽기용 지도를 제공한다.
- 사용자 확정 경계: 재기획은 독립 그래프로 만들고 기존 자료는 참고 관계로만 연결한다. 기존 그래프에 통합하거나 기존 정책을 새 기획으로 자동 승계하지 않는다. 과거 기획·현행 구현·조사 결과는 외부 참고이며 채택과 구분한다. 기존 그래프를 변경하지 않는다.
- 기준: 확정 방향, 제안·설명용 사례, 미정 설계, 구현 상태를 구분한다. 관계를 정리하며 새로운 제품 결정을 만들지 않는다. 최신 합의가 이전 기록을 구체화한 부분과 현재 구현과의 간극을 드러낸다.
- 범위: 연결된 코어키퍼 기록 및 기존 그래프의 관련 자료. 게임 행동 전수 데이터는 조사 근거로 연결하며 기획 연결 요청을 게임 모드 구현이나 전수 능력 비교로 확대하지 않는다.
- 보존: 제품 코드·실행 캐릭터·context.md를 변경하지 않는다. 게임·외부 LLM 호출 보류를 유지한다. 과거 작업자 모델 지정은 현재 강제로 적용하지 않는다.
- 완료 확인: 대표 질문을 따라 핵심 경험 → 목표·계획 → 필요한 정보·행동 → 원문까지 탐색한다. 기존 구현/공백으로 건너갈 때는 참고 경계를 명시한다. 독립 검수로 근거와 상태 구분 및 기존 기획 비승계를 확인한다.
