# 검색 경로 오프라인 시뮬레이션

2026-11-07. 사용자가 최근 합의의 검색→계획→행동 흐름과 Decisions에 검색을 맡기는 제안을 게임 없이 시험해 달라고 요청했다.

## 목적과 비교

- A: 같은 새 부탁·현재 관찰 → 위쪽 LLM이 필요한 기억 검색 → 작업 계획 → Decisions의 첫 구체 행동 → 모의 실행 검사.
- B: 같은 새 부탁·현재 관찰 → 위쪽 LLM의 작업 → Decisions가 검색/행동을 선택 → 필요하면 위쪽 LLM으로 계획 변경 요청 → 첫 구체 행동 → 모의 실행 검사.
- 판단 기준은 첫 유효 행동까지의 전체 시간, 검색·모델별 시간과 호출 수, 검색 근거 사용, 준비 조건의 충족이다. 목표 전체 완수·실제 게임 성공은 측정하지 않는다.
- 정상 위치 확인, 준비 조건 때문에 계획 변경 필요, 낡은 기억의 세 장면을 각 경로 한 번씩 실행한다. 첫 장면을 연결 확인 겸 사용한다. 동일 기준으로 비교하고 탐색 시작과 확정 목적지 이동은 구별해 보고한다.

## 조건과 경계

- 현행 ChatGPT 제품 구성과 Decisions 제품 구성을 사용한다. 직접 실행하는 개발 에이전트의 모델 지정이 아니다.
- 기존 CLI 어댑터·로그인/사용량 검사, 기존 기억 엔진을 재사용한다. 게임과 운영 브리지는 켜지 않으며 운영 코드·설정·기록·context.md를 바꾸지 않는다.
- 실제 모델을 호출하고, 장면/몸 실행은 격리된 합성 fixture로 모의한다. 실제 게임 데이터 재생이나 게임 물리/경로 검증으로 표현하지 않는다.
- 검색을 할지의 선택을 모델에 맡긴다. 판정용 숨은 사실과 기대 답은 모델 입력에 넣지 않는다. 검색 생략과 오류도 결과로 남긴다.
- 위쪽 LLM은 경로당 최대 3회, Decisions는 경로당 최대 5회 호출을 우선 상한으로 한다. 완료 시 조기 종료한다. 추가 호출은 새로 발견된 시험 결함이나 실패를 해결할 때만 제한적으로 한다.
- Decisions 검색은 신규 제안의 시험이다. 새 역할·API·호출 간격을 제품 합의나 구현 완료로 확정하지 않는다.
- 이번 요청으로 제한적 오프라인 모델 호출을 수행한다. 과거 중단했던 실게임·기지 4a 작업을 재개하는 것이 아니다.
