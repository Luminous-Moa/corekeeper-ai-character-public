# 전투 현황 진단 범위

- 문제: 현재 AI 캐릭터 전투에서 살아남고 목표를 이어 가는 데 무엇이 부족한지 파악한다.
- 결과: 현 코드와 최근 실게임의 관측 → 후보 → 모델 선택 → 실행 → 피해·사망 흐름을 연결한 근거 있는 진단. 주요 문제의 영향과 우선순위, 확정 사실과 미확인을 구분한다.
- 조건: 진단 요청이다. 제품 코드·설정·게임 상태를 바꾸지 않는다. 전투 전술은 모델이 판단하고 빠른 판단을 살리는 선택지 설계라는 기존 사용자 기준을 적용한다. 다른 대화의 기억 검색 작업과 게임 사용을 방해하지 않는다.
- 출발 자료: 전투 선택지·전투 안정/동료 인식·전투 로그 판단검토 기록, 최신 기억 검색 실게임 기록, 게임 지식그래프 무기 피해 확인, 현 CoreKeeperModSDK 소스.
- 현황: 조사 시작 시 주 작업 트리는 1c2a94c detached이며 기억 검색 시험본이다. ai-character 기준과 차이가 있으면 진단에 명시한다.
