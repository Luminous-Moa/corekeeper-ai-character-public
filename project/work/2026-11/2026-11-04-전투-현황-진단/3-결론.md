# 현재 전투 시스템 진단 — 결론

## 판단

가장 큰 구조적 문제는 빠른 판단에 비해 모델이 볼 수 있는 전투 정보와 고를 수 있는 조작이 부족하다는 점이다. 위험을 알고도 부적절한 방향을 고르는 실제 판단 문제도 남아 있다. 응답 속도나 단일 모델의 지능만으로 전체를 설명할 근거는 없다.

## 중요한 문제

1. **전술 관측 부족.** 적의 위치·거리·체력은 주지만 공격 준비, 공격 방향, 위험 범위, 공격 뒤 틈을 판단에 전달하지 않는다. 적이 언제 위험하고 언제 때릴 수 있는지 구분하기 어렵다. 게임 참고본에 관련 상태 데이터 후보가 있지만 해당 적의 실제 프리팹과 연결·가시성은 더 확인해야 한다.
2. **큰 동작 위주의 선택지.** 붙어서 계속 공격, 최대 3초 거리 벌리기, 코어 복귀, 먹기, 기다리기 중심이다. 한 번 치기, 짧게 옆으로 피하기, 사거리를 유지하며 공격하기 등 정교한 전투 동작을 모델이 고를 수 없다. 빠른 재판단만 늘려서는 이 능력이 생기지 않는다.
3. **근접에 묶인 실행과 무기 선택.** 공격은 1.3칸까지 붙는 실행이고 무기는 근접 무기만 고른다. 최신 실제 기록에서 석궁을 소지한 캐릭터가 부서진 목검으로 싸웠다. 사망 기록의 wpn은 실제 손무기가 아니라 가방의 최고 레벨 근접·원거리 무기 요약이므로 별도로 해석해야 한다.
4. **코어 복귀와 안전한 후퇴가 다르다.** 코어 부근에 강한 적이 있으면 복귀가 다시 위험 속으로 들어가는 행동이다. 모델이 적 쪽으로 이동한다는 경고를 받고도 복귀를 선택한 최신 사례에서, 이동 직후 쓰러졌다. 선택지 표현·경로·목적지 정보와 이를 받은 모델의 위험 판단을 함께 다뤄야 한다.
5. **빠른 전환이 유효한 전투 진행으로 이어지지 않는 경우.** 최신 대표 구간은 긴급 전환 없이도 짧은 시간 여러 번 행동을 바꿨다. 단순히 긴급 판단의 빈도만 줄이는 방식으로 원인을 다 설명할 수 없다. 선택 당시 정보와 실행 시점의 상태를 연결해서 보아야 한다.

6. **피해 학습의 귀속과 상태 구분.** 대상 체력 감소를 내 타격으로 기록해 동료 피해가 섞일 수 있고, 받은 피해의 공격자도 근처 적으로 추론한다. 공격 도중 무기가 부서져도 학습 키가 즉시 바뀌지 않는다. 이런 값으로 처치 시간과 생존 시간을 비교하므로 무리전과 상태 변화에서 추정이 흐려질 수 있다.

## 검증 범위와 제외

- 상세 코드와 실제 로그 근거는 [상세 진단](2-상세진단.md)에 둔다.
- 최근 기존 실게임 시험에서 쓰러짐 18회 중 15회는 버섯 야수가 최근접 적으로 기록됐다. 이는 실제 가해자가 모두 버섯 야수였다는 확정도, 전후 개선 효과를 재는 대조 실험도 아니다.
- 같은 시험 범위 하위 판단 응답은 9,357건, 중앙값 약 0.26초, p95 약 0.45초다. 상위 목표 LLM 시간과 구분한다.
- 과거 요청의 계속하기가 이미 바뀐 행동을 유지시키던 결함은 현재 코드에서 key 대조로 수정되어 최신 로그의 정상 폐기도 확인됐다. 현재 미해결 문제로 다시 세지 않는다.
- 무기 기본 피해를 읽지 못하던 문제도 수정됐다. 실제 장비·상태·대상에 맞는 피해 추정 문제는 별도로 남는다.
- 새 실게임을 실행하거나 제품 코드·설정·게임 상태를 변경하지 않았다. 기존 실게임의 대표 흐름을 추적한 읽기 전용 진단이다.

## 다음 작업을 고른다면

우선 실제 전투 입력과 조작 능력을 보완할 범위를 정하는 것이 타당하다. 적의 화면에 보이는 전조와 짧은 동작, 원거리·무기 상태를 일치시킨 뒤 같은 시험장에서 선택→실행→피해를 비교한다. 후퇴에는 실제 목적지·이동 방향의 위험을 분명히 나타낸다. 모델 전술 선택 원칙을 유지하며, 호출을 늦추거나 자동 회피로 대체하는 것을 이번 진단의 결론으로 삼지 않는다. 구현 범위·수치·순서는 아직 결정하지 않았다.
