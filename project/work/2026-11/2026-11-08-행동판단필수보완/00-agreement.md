# 행동 판단에 필요한 정적 연결 보완

사용자 요청: “필요하긴 한 거지? 그러면 보완해줘”. 앞서 확인한 여섯 후보와 추가 네 범위에서 실제 판단·행동 조건·비용·결과·실패 후 선택에 필요한 부분을 검토하고 정본에 보완한다.

목적은 AI가 코어키퍼 안에서 상황에 맞는 구체적 행동을 선택하고 수행할 수 있게 하는 근거 연결이다. 정확한 원본·코드에서 확인되는 정적 사실만 기록한다. 기존 노드와 동등한 의미는 재사용한다. 순수 연출, 자동 코드 목록 채우기, 무관한 구현 세부 확대는 제외한다.

입력은 246수용묶음 정본 published/와 기존 조사 보고서다. 루트3JSON은 이전 입력이다. 기존 six: grapple8373/8374 발동·조준, lightning9135 최초/chain target, Effect58 입력 gate, 6839 Condition39→Effect2, 3101 Condition102→Effect59, 1355/5875/5942/5953 Condition206→None 귀속. 추가 four: 번식 후속, dash8340/8341, minion detonator8330/8331, 사망·부활 lifecycle.

완료 조건: 각 범위 기존/추가/보류 판정과 원문 근거, 필요한 연결의 생성·통합, 독립 원문/생성규칙 검수, 기본 CLI의 대표 입력→조건→소비/결과 조회, 게시 실물 독립 검수와 기존 자료 보존 확인. 정적 생성 요청과 실제 성공은 구별하며 runtimeTested=false를 유지한다.

게임·모드·세이브·실제 모델 호출·연출 분리는 범위 밖이다. context.md와 원본은 수정하지 않는다. 기존 historical-pin-alias를 보존하고 설치 Steam 메타데이터 변경을 과거 원문 재핀으로 덮지 않는다.

세부 생산·실행과 독립 검수는 별도 컨텍스트에 맡기고 HEAD는 목표·범위와 수용 판단을 유지한다. 확정 네 범위를 넘어 미완 A/C·수면·탈것 등의 새 전수조사는 이번에 추가하지 않는다.
