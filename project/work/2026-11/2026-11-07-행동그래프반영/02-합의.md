# 대상·행위·조건·결과 그래프 반영

## 사용자 목적

지금까지 수집·검수한 게임 자체의 대상·행위·조건·결과를 해당 연구 그래프에서 연결해 조회할 수 있게 한다. 사용자는 반영 후에도 빈 곳이 남는지 알고자 한다. 대상은 현재 AI가 실행 중 조회하는 지식그래프나 개발 제품 그래프가 아니라 지금까지 작업한 게임 행동 체계다.

## 입력과 보존 조건

- work/게임원본-상호작용의 고정 원본·최종 의미 분석, 2026-11-07-행동전체추출의 검수된1432행·요리6561쌍, 2026-11-07-상호작용미결보강의949행·미결1671판정 및 근거를 재사용한다.
- 대상 source 신원과 objectId/variation, 행동·단계·보강 관계를 보존한다. 같은 이름/ID 또는 같은 source×action만으로 의미를 합치지 않는다.
- 가능 조건·입력·실패·결과·근거·미결을 연결한다. 사실단계/입구/조건부 정적 연결과 플레이어의 의도적 행동을 구별하며, asset_link/code_linked를 런타임 성공으로 승격하지 않는다.
- 기존 추출 원본을 덮지 않고 생성 절차로 그래프를 재생성한다. 기존 자료의 잘못된 해석을 조용히 교체하는 대신 보강·정정 근거를 따라갈 수 있게 한다.
- 단순 파일 연결뿐 아니라 대상→행위→조건/결과→원본 근거를 실제 조회하는 대표 흐름을 검증한다. 미결과 적용범위 밖도 조회 가능해야 한다.
- 게임·모드·세이브·현재AI조회 지식·독립 재기획 그래프는 변경하지 않는다. 실게임 보류는 유지한다.

## 진행 범위 재확인

사용자는 행동 결과 그래프를 원래 목적대로 계속 진행하고, 게임 지식그래프는 별도로 진행하겠다고 확정했다. 이번 결과에는 게임 내 LLM 조회·기존 knowledge 그래프의 통합/교체·공개 정책 구현을 포함하지 않는다. 앞선 조회 구조 비교는 검토 의견으로 보존하며 아키텍처 승인으로 바꾸지 않는다.

## 완료 기준

실제 그래프 생성·조회와 입력 보존, 참조 무결성·중복/보강 경계·결정적 재생성을 검증하고 별도 컨텍스트의 독립 검수에서 필수 지적을 수정한다. 완전성 평가는 source 전수 처리와 전체 행동 발견을 구별하여 근거가 있는 빈 곳을 명시한다.
