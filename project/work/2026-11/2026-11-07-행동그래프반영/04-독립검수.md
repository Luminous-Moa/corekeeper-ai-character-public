# 게임 행동 그래프 독립 검수

2026-11-07. 최종 판정: **통과**. 예비 검수의 필수 지적 3건을 구현자가 수정했고, 동결된 최종본에 대해 독립 전수 대조·실제 CLI 소비·결정적 재생성 검사를 완료했다. 미해결 필수 지적은 없다.

검수 대상은 `work/게임행동-그래프/`의 대상·행위/단계·조건·결과 파생 그래프다. 현재 AI 지식그래프 연결, 런타임 실행 가능성, 새 행동 추출은 이번 완료 기준에 포함하지 않았다. 검수자는 구현 모듈을 가져다 쓰지 않는 별도 스크립트로 원본과 생성 자료를 대조했다. 세션 연결/저장 도구를 사용하지 않았으며, 작성 위치는 이 보고서와 `review-evidence/`뿐이다.

source의 이름·ObjectID·variation을 원문과 전수 대조했으며 이름/ID가 같다고 합친 흔적은 없다. 보강 인덱스가 명시한 priorRecordIds와 모든 stageLinks도 관계로 존재한다. 숫자 ID 참조는 source 신원을 대신하지 않는다.

표준 JSON 파싱에 성공했다. 63,331개 pathID/주소 필드는 문자열이며, 안전 정수 범위를 넘는 JSON 숫자는 발견하지 못했다. 원래 비표준 Infinity는 양의 무한대 의미 태그 25개로 보존되어 null로 소실되지 않았다.

manifest가 고정하는 1,030개 파일의 실제 해시를 대조했다. 원본 3개 작업 트리의 작업 전 스냅샷에 포함된 manifest 입력은 시작 시점 해시와 동일했다. 이 검사 범위에서 원본·구 추출의 변형은 없다. 게임·세이브·제품·AI 경로를 실행하거나 수정하는 작업은 수행하지 않았다.

## 실제 사용자 조회 흐름

- **상자**: 이름 검색 → ObjectID 100의 정확 source → 초기 `open_inventory` 주장 → 플레이어 조건·UI 결과 → 원문 asset/code 근거를 조회했다. 기존 상자·배치 자료가 후속 행으로 대체되지 않았다.
- **수리**: `target 1` → baseline repair → 들어오는 보강 관계 → supplement repair → 기존 B 공통 규칙의 조건·재료 산정·실패·결과와 catalogSelection/dynamicRepairResolution을 확인했다. 원래 규칙과 최신 선택 보강을 한 행으로 덮지 않는다.
- **압력판**: 이름과 variation 0 선택 → C 보강의 기본 플레이어 필터 → 명시 `path` → A 전력 전파 조건·실패·결과를 조회했다. `electrical_fact_stage`는 실제 부하 결과를 보장하는 플레이어 행동으로 표시되지 않는다.
- **D 소비 결과**: `automatic_recipe_result` 행 자체에 조건·결과가 없어도 `show`가 공통 규칙의 실제 조건, 자원 소비/결과, 실패 분기와 런타임 미관측을 반환했다.
- **요리 순서**: 1645→1646과 1646→1645를 별도로 조회했다. 입력 순서와 두 source가 보존되며 조건부 계산으로 표시된다. 이 예시의 출력 variation이 같은 사실을 두 순서행 병합 근거로 사용하지 않는다.
- **6506/4600**: 6506의 네 variation을 확인했고 enum 값 3의 특수 의미는 unresolved다. `target 4600`은 가짜 source를 만들지 않고 고정 추출 부재의 의미와 `gap:D-4600` 조회 안내를 반환한다. 해당 gap에는 원본 부재·fallback 해석 한계·근거가 있다.
- **수동 삽**: `dig_shovel` 결과는 `digStateStarted=true` 그대로다. 대상별 최종 파기 완료로 승격하지 않는다.
- **주장 없음/최신 판정**: 후속까지 주장 없는 source가 “기록되지 않음, 불가능 아님”으로 반환된다. C-filter의 정적 해결, D-map1513의 특정 graphical 경로 비적용, runtime 미관측을 별도로 조회했다. 초기 Baker/ECS 문구 전체가 보강 source 존재만으로 자동 닫히지 않는다.
- **상대 근거 파일**: baseline A 앉기 주장의 `source` 응답에서 evidenceContext를 받아 `evidence/rules.md`를 실제로 열었다. 원래 그룹 경로와 공유 코드 경로를 잃지 않는다.

모든 명령·종료 코드와 JSON 응답은 [audit-result.json](review-evidence/audit-result.json) 및 `review-evidence/cli-*.json`에 있다. 근거 파일 열람 사본은 [opened-sit-evidence.md](review-evidence/opened-sit-evidence.md)에 있다. 기존 개발 지식그래프 README의 행동 그래프 진입 링크도 확인했다.

## 결정성과 완료 범위

최종 `check`가 메모리에서 두 차례 재생성한 graph/coverage/manifest는 게시 파일과 모두 바이트 일치했다. 별도로 검사 전후 graph.py/graph.json/coverage.json/manifest.json 해시가 같음을 확인했다. 근거는 [determinism-check.json](review-evidence/determinism-check.json), [published-before-after.json](review-evidence/published-before-after.json)이다.

**통과는 알려진 자료를 행동 그래프에 보존하고 실제로 따라 읽을 수 있다는 판정이다. 빈 곳이 모두 사라졌다는 판정은 아니다.** 초기 무상호작용 source 592개 중 모든 보강 후에도 주장 없는 source 590개가 남고, 이를 곧바로 미발견 행동 수로 세지 않는다. 회로 6506·제품 4600, 일부 시작 단계의 후속 결과, 실제 월드/미래 tick/실행 성공, 좌표·액체·추상 상태의 독립 census, 전체 행동 계열 발견은 여전히 제한된다. 고유 게임 행동 총수는 null, runtimeTested와 completeGameActionEnumeration은 false로 유지된다.
