# 대상·행위·조건·결과 그래프 구현 결과

## 결과

정본 추출물을 변경하지 않고 [게임 행동 그래프](../../게임행동-그래프/README.md)를 생성했다. `graph.py`가 원래 상호작용·전체추출·미결보강·요리 관계를 읽어 source별 대상→행위/처리단계→조건·결과·실패→근거를 연결한다. 같은 게임 사실의 파생 조회이며 사실의 별도 수작업 정본이 아니다.

출력은 `work/게임행동-그래프/graph.json`, `coverage.json`, `manifest.json`이다. `README.md`는 사용 설명이며 데이터와 집계는 생성기가 소유한다. 전체 모드·게임·현재 AI 지식·세이브·재기획 그래프 및 기존 추출물은 변경하지 않았다. 외부 LLM 호출·실게임도 하지 않았다.

## 반영 단위

| 단위 | 개수 | 뜻 |
|---|---:|---|
| source | 3,235 | 고정 원본 신원; variation과 여러 prefab을 보존 |
| 초기 상호작용 주장 | 3,499 | 원래 final의 행위 설명 |
| 기본 추출 행 | 1,432 | 검수된 행동 계열의 전수 적용 |
| 보강 행 | 949 | 기존 근거 보강·조건·선행/소비/자동화 단계 포함 |
| 요리 순서쌍 | 6,561 | 입력 source 순서를 보존한 조건부 결과 |
| 초기 미결 문구 | 5,090 | 반복되는 공통 범위 설명 포함; 실제 미결 개수와 다름 |
| 후속 source×rule 판정 | 1,671 | 과거 unknown과 현재 판정 연결 |

그래프는 53,699개 노드와 74,281개 관계다. 주장 5,880개를 고유 게임 행동 수라고 부르지 않는다. 초기 주장 없는 source는592개이고 모든 보강 후에도 기록된 주장이 없는 source는590개다. 이는590개가 모두 상호작용 가능한데 누락됐다는 뜻도, 불가능하다는 뜻도 아니다.

공통 규칙63개를 실제 연결했다. 보강B의 규칙은 기본B에서 찾고, 보강D는 행에 없는 조건·결과·실패를 공통 규칙에서 펼친다. 행과 규칙 내용이 함께 있는 경우 출처별로 모두 유지한다. C 입력→A 전력의 명시 연결19개와 producer가 선언한 source/variation 참조도 보존했다.

## 실제 조회와 검증

실행법과 명령의 결과는 [대표 CLI 검증](implementation-evidence/run.py)과 [결과 집계](implementation-evidence/summary.json)에 있다. 이 스크립트는 생산 출력에 쓰지 않고 실제 `graph.py` 프로세스를 실행한다.

- 상자 ObjectID100의 정확 source→open_inventory 주장→조건/결과→코드 근거 원문을 조회했다.
- 수리 ObjectID1에서 기본/보강 관계, catalog 선택 조건과 기본 공통 규칙 결과를 조회했다.
- 압력판 C 입력에서 명시된 `declared_input_for` 관계를 따라 A 전력 단계에 도달했다.
- D 자동 제작 행에서 공통 규칙의 조건·결과·실패를 실제 출력했다.
- 요리1645→1646의 입력 순서와 조건부 결과를 조회했다.
- 2406의 현재 비적용 판정,6506의 enum 미결,4600의 원본 부재와 다음 조회를 확인했다.
- 숫자1 조회가 이름에1이 든 다른 대상과 섞이지 않는 것을 회귀 확인했다.

`check`는 두 번 새로 생성한 graph/coverage/manifest를 게시 파일과 바이트 단위로 비교하고, 입력1,030파일의 고정 해시, 모든 origin의 JSON pointer·정규화값 해시, 관계 끝점과 전수 단위 보존을 검사한다. 원본의 bare Infinity는 명시적 `floatSpecial` 객체로 보존하여 strict JSON을 생성한다. 조회 프로세스는 코드·그래프·coverage·manifest를 변경하지 않는다.

독립검수에서 숫자ID 조회의 이름 혼입,4600 무source 응답의 설명 부족, 상대 근거 경로의 기준 부재를 지적받아 수정했다. node와 `source` 응답의 `evidenceContext`에 package·manifest·group base·원문 referenceContext 및 해석 경로를 제공한다. 최종 판정과 별도 재현은 [독립검수 보고서](04-독립검수.md)를 따른다.

## 남는 경계

현재 그래프 반영은 입력 추출물의 근거와 판정을 따라갈 수 있게 한 것이다. 회로6506의 원본값3/동일빌드 enum 차이, 고정 원본에 없는 제품4600, 임의 미래tick·실제 월드배치·충돌·타이머·네트워크·난수 결과를 해결했다는 뜻은 아니다. 일부 행동 계열은 시작 단계만 규명돼 있고 후속 결과까지 전부 연결됐다고 확인하지 않았다. 좌표·액체·추상 상태의 별도 전수 모집단과 모드 능력 비교도 아직 없다.

이름이 같은 원본과 행위를 임의로 합치지 않았고, 보강행이 있다는 이유로 초기 Baker/ECS 공통 미결을 자동 폐쇄하지 않았다. 입력 파일은 향후에도 현재 manifest의 근거와 함께 유지해야 한다. 게임 지식그래프의 실시간 AI 조회나 공개 정책 반영은 사용자 지정대로 별도 작업이다.
