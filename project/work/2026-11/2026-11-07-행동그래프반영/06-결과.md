# 행동 결과 그래프 반영 완료

[게임 행동 그래프 안내](../../게임행동-그래프/README.md)에서 대상 검색→source/variation 선택→행위·처리 단계→조건·결과·실패→원본 근거를 조회한다. 기존 검수된 추출 자료를 읽는 파생 그래프이며 생성 JSON을 직접 수정하지 않는다.

## 반영한 자료

- 고정 원본3,235 source와 초기 상호작용3,499건.
- 전체 추출1,432행과 후속 보강949행. 합계5,880은 출처별 주장 수이며 고유 게임 행동 수가 아니다.
- 순서가 있는 요리 조합6,561쌍.
- 초기 역사적 미결5,090문구 및 후속 source×rule 미결1,671건의 현재 판정. 같은 단위로 합치거나 잔여 공백 수로 해석하지 않는다.

행 자체와 공통 규칙의 조건·결과를 모두 전개하고, 보강·선행·소비 관계를 명시된 근거대로 잇는다. 기존 개발 그래프 README에도 진입 링크를 추가했다.

## 검증

[구현 결과](03-구현결과.md)와 [독립 검수](04-독립검수.md)를 확인한다. 필수 지적3건(숫자ID 검색, 원본 없는4600의 미결 안내, 상대 코드근거 기준경로)을 수정하고 재확인했다. 독립 검수는24개 실제 CLI 흐름, 모든 핵심 단위의 원본 대응,51,176개 원본 포인터,1,030개 입력 파일, 두 차례 재생성과 게시본 바이트 일치를 확인했다. 필수 잔여 지적은0건이다.

대표 흐름은 기존 상자 사용, 수리의 기본→선택 근거 보강, 압력판→플레이어 필터→전력 전파, 공통 규칙의 제작 결과, 요리 순서쌍,6506/4600 미결 조회다. 코드·정적 근거 조회 검증이며 실제 게임 실행 성공으로 확대하지 않는다.

## 빈 곳은 남아 있다

그래프에 자료를 빠짐없이 연결한 것과 게임의 모든 행동을 규명한 것은 다르다. [완전성 평가](01-완전성평가.md)에 근거를 정리했다.

- 보강 후에도 행동 주장이 없는 source590개가 있다. 불가능이 아니라 현재 수집 자료에 주장이 없다는 뜻이다.
- 삽·광선·소환·특수UI 등 일부 경로는 시작/입구까지 확인했으며 대상별 조건·후속 결과가 모두 완결된 것은 아니다.
- 회로6506의 원본값과 코드enum 불일치, 제품4600의 고정 원본 부재는 미결이다.
- 좌표·액체·추상 상태의 독립 전수 범위, 모든 행동 계열 발견, 실제 월드 결과 및 모드의 제공 능력 비교는 별도 확인이 필요하다.

게임·모드·세이브·기존 추출물과 게임 내 LLM의 현재 지식 조회 경로는 변경하지 않았다. 사용자가 지정한 대로 게임 지식그래프 작업은 별도 후속으로 남겼다. 관련 논의는 [LLM 조회 검토](05-LLM조회검토.md)에 권고와 확정 범위를 구분해 보존했다.
