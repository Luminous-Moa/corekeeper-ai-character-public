# 행동 범위 누락 조사

## 요청과 결과

장비 보관과 아이템 버리기 외에도 플레이에 필요한데 AI가 수행하거나 고를 수 없는 행동을 찾는다. 기존 선택지의 설명·정확성 검토와 달리 행동 범위 자체의 누락을 조사한다.

## 판단 기준

- 사람의 플레이 흐름에서 어떤 일이 막히는지 구체적으로 적는다.
- 상위 목표로 지정 가능, 하위 모델 선택 가능, 코드 자동 실행만 가능, 기본 기술만 있음, 실행 기능 없음으로 구분한다.
- 구현 부재와 의도된 정책 제한을 구분하며, 기록 근거 없이 사용자 결정으로 돌리지 않는다.
- 이미 구현된 일부 동작이나 진행 중인 기지4a/4b를 완전 미구현으로 분류하지 않는다.
- 현재 본 코드 b25099f를 기준으로 하고 다른 작업의 UI 시험 설치/진행 중 코드는 구분한다.
- 초반 기지 생활과 당장의 인벤토리·장비 관리에 필요한 것을 우선 평가하고 나중의 보스/이동수단 같은 확장은 별도로 표시한다.

## 범위

읽기 전용 조사다. 코드·게임·설치·모델을 변경하지 않고 GUI 자동 조작도 하지 않는다. 사용자는 현재 게임을 직접 플레이하고 있다. 결과는 근거와 우선순위를 갖춘 목록이다. 구현 범위와 정책 변경은 이 조사에서 확정하지 않는다.
