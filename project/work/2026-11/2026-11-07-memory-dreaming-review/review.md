## 중요 수정 1건 — 반영 확인 완료

**P2 — 기본 장면의 실제 완료 성능이 이미 검증됐다는 인상을 제거한다.**

- 위치: [comparison.md:78](comparison.md:78), 가장 작은 비교 실험의 첫 장면.
- 현재 문장: “현재 구조로 이미 잘 되는 장면에서 퇴보가 없는지 확인한다.”
- 문제: 이 장면은 광맥 발견 후 기억을 이용해 부탁을 수행하는 전체 흐름이다. 확인된 현행 근거는 공간 기억의 후보 연결, 실제 저장 기록의 색인·조회, 합성 장면의 첫 행동/모의 수락이며, 해당 장면의 실제 이동·철 확보·부탁 완료가 검증됐다는 근거는 아니다. 본문의 다른 절에서 이를 잘 구분했지만 이 문장만은 성공한 기존 기준 성능을 전제한다.
- 권고: “기존 기억 경로가 연결된 기본 장면에서 먼저 기준 성능을 확인하고, 정리 적용 후 퇴보 여부를 본다.”처럼 바꾼다. 실제 완료 성능이 미확인인 기준군을 실패·성공 모두 관측할 대상으로 남긴다.
- 근거: [기존 실게임 시험 초안](../2026-11-07-기억-실게임시험계획.md), [로컬 근거의 실제 기록 추적과 한계](local-evidence.md), 본문의 600회 합성 시험 제한 설명.
- 재확인: 부모가 “기존 기억 경로가 연결된 기본 장면에서 실제 완료까지의 기준 성능을 먼저 확인하고 정리 후 퇴보 여부를 본다”로 수정한 내용을 파일에서 확인했다. 지적은 해소됐다.

## 나머지 판정

기존 구현, 방향 합의, 이번 제안이 구분되어 있고 자유로운 교훈·관계 편집을 승인된 기능으로 확장하지 않는다. 현재 상태의 변경과 과거 사건의 진실, 관측 실패와 반증, 같은 근거의 반복 처리도 적절히 구분한다. 원본이 무손실 transcript가 아니라는 한계와 원본 조회의 공백을 선행 점검으로 반영한 우선순위는 타당하다.

[Anthropic 기사](https://www.anthropic.com/research/components-of-agent-memory)의 결과를 코어키퍼의 성과로 일반화하지 않으며, [Cookbook](https://platform.claude.com/cookbook/managed-agents-cma-dreaming-with-a-dynamic-workflow)의 기존 저장소 갱신 방식과 별도 Dreams의 새 저장소 방식을 구별한다. 예제의 동시 편집·야간 커서를 그대로 도입하지 않고 작은 후보 실험으로 한정한 판단에도 중요한 문제를 발견하지 못했다.
