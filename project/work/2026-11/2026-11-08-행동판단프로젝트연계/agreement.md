# 행동 판단 그래프의 프로젝트 연결

사용자는 조사 결과를 바탕으로 연결 가능한 범위를 최대한 연결하도록 요청했다.

목표는 개발자가 기존 프로젝트 지식그래프의 기획·기능·구현에서 관련 게임 행동의 조건·결과·실패와 원문을 조회하는 흐름이다. 기존 채굴·문·다리의 수동 참조를 출발점으로 삼고 확인 가능한 다른 생활·전투·이동 등의 연결도 조사해 적용한다. 상세 근거는 게임 행동 그래프의 현재 게시본을 재사용한다.

완료 판단에는 프로젝트의 정상 조회 진입점에서 실제 게임 규칙 원문까지 이어지는 대표 실행과 추가 연결 범위·미연결 이유의 근거가 필요하다. 기존 기획·코드의 지위와 검토 당시 근거를 보존한다. 정적 규칙의 연결은 실게임 성공 증거와 각각의 지위로 표시한다. 이름이나 ObjectID만으로 서로 다른 sourceKey와 variation을 합치지 않는다.

코어키퍼 세션의 행동판단-프로젝트연결 브랜치에서 수행한다. 세부 조사·생산은 별도 실행 컨텍스트가 맡고 독립 검수 후 HEAD가 이 합의와 결과를 대조한다.
