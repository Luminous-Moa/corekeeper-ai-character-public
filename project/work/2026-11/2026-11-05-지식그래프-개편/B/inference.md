# B-7 코드만 보고 쓴 추정

기준 커밋: `e82eb87f25641cc7c31e6216f64e20a34e58d0c0`. 이 문서는 B-1~B-6을 수행하지 않은 별도 코드 시선에서 작성했다. 입력은 B/code.graph.json, B/meanings.json과 B/snapshot의 소스다. A 결과와 기존 제품 기획·정책·화면 문서를 의도적으로 열지 않았다. B-6 뜻은 해석 보조이며 아래 근거는 고정 소스의 파일·줄이다.

**관측 한계.** 게임, 브리지, CLI를 실행하거나 화면·조작·HTTP 전송·외부 호출을 관측하지 않았다. 모든 화면·요소·활동·정책·제품 정의는 코드만 보고 쓴 추정이다. 여기서 화면은 정의서의 화면 없는 제품 규칙에 따른 **출력 한 종류**다. 게임 채팅은 기존 게임 UI의 출력 경로를 빌린 것으로 추정하며, 별도의 페이지·버튼·메뉴를 의미하지 않는다. health/plan JSON·SDK 로그 역시 추정 출력이며 실제 받은 출력 원문이나 스크린샷이 없다. 따라서 원본 그림·위치 매칭본·실행 성공 증거를 제공하지 않는다.

**입력 격리 사고.** 소스 검색 한 건에서 PowerShell과 rg의 따옴표 전달 오류로 C:/Dev 전체 검색 결과 일부가 출력되었다. 즉시 중지했다. 화면에 보인 외부 결과는 타 프로젝트 및 _share 코드 일부였으며 이를 추정 근거로 사용하지 않았다. A 결과나 기존 코어키퍼 기획 내용을 확인하여 사용한 적은 없다. 부모 컨텍스트에 사고를 보고한 뒤 지정 snapshot의 -LiteralPath 읽기로 제한하여 계속했다. 완전한 입력 격리가 필요할 경우 이 사고를 고려해야 한다.

**모델링 범위.** 출력 읽기만 확인되는 요소에 `화면요소→기능`을 임의 생성하지 않았다. 명령 요청은 활동의 단계에 적고, 코드에 확인된 응답은 `기능→화면요소`로 연결했다. 채팅 명령 입력 위젯의 구조, 출력 클릭, navigate, 화면을 여는 순간의 호출은 미확인이므로 간선이 없다. 제품코어·저니·IA는 정의서에 따라 연결 간선 없이 속성과 본문으로 기록한다. 런타임 내부 로그 전부와 모든 시험 명령별 결과를 완전 복원한 문서는 아니다. 조건 분기 문구가 같은 사용 목적의 출력 종류에 속하면 같은 추정 화면에 기록했다.

# 통합 시 남겨야 할 미확인 사항

- 실제 게임에서 명령 접수·응답 표시·입장·퇴장·캐릭터 저장 및 목표 수행이 되는지 A/D의 관측으로 확인해야 한다. Reply의 로그 또는 반환 객체만으로 실제 표시·전송을 주장할 수 없다.
- health는 메모리에 보관된 사전 점검 상태를 반환한다. GET 호출마다 로그인·사용량을 새로 확인하는 것으로 추정하지 않는다.
- 상위 계획은 구독 CLI, 행동 선택은 별도 OpenAI Decisions 경로로 보인다. 브리지에서 API 키 환경 변수를 제거하는 코드와 게임의 KeyMissing 안내는 서로 다른 프로세스·용도다. 사용자 과거 작업 모델 지정 철회와 제품 자체의 모델 설정을 혼동하지 않는다.
- farm/cook 잊기는 코드 주석상 시험용이지만 TestCommands 목록에 없다. B-7에서는 존재하는 경로만 기술했으며 정책 의도를 수정하거나 파일을 변경하지 않았다.
- 구독·사용량·모델·외부 어댑터 상태는 실제 서비스의 현재 사실이 아니다. 고정 커밋의 분기만 기록했다.
- code.graph.json의 possible=true 참조 또는 동적 외부 경계는 실행 증거로 간주하지 않았다. 관련 근거는 허용된 snapshot 소스의 파일·줄로 한정했다.
- 본 문서의 상위 문서·활동·출력 그룹은 기존 제품 의도와 다를 수 있다. C에서 기준 기획과 조정하고 D에서 실제와 대조해야 한다.
