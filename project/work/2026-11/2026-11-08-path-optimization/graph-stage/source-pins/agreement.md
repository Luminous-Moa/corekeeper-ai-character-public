# 길 계산 최적화 구현 합의

사용자는 앞서 확인한 코드 문제의 최적화를 요청했다.

목표는 Gemini 응답 이후 후보 준비에서 발생한 중복 경로 계산과 캐시 전체삭제, 수천 목적지의 동기 처리를 개선하여 게임이 장시간 멈추는 원인을 해소하는 것이다.

모든 후보와 행동 선택권, 선택 전 필요한 위험 정보, 도구·문·목적지 예외, 지식 공개 및 정상 게임 조건을 보존한다. 기존 합의에 따라 후보 상한·목표별 숨김·대표지점 압축을 임의로 복원하지 않는다.

구현은 격리된 작업 소스에서 진행하고, 실제 생산 경로와 연결된 대표 시험·회귀·Unity 컴파일 및 독립 검수를 통해 수용한다. 실제 게임 설치 상태와 실기 여부는 구분하여 기록한다. 기존 사용자 작업·세이브를 보존한다.
