# 몸 동작의 정책 종료를 실행 관측으로 전환

기반 worktree는 `C:/Dev/CoreKeeperModSDK-common-execution`이다. 수정 대상은 AIAttackSkill, AIMineSkill, AIBreakSkills, AITunnel, AICombat, AIShortSkills, AINavigator의 일곱 파일이다. 공통 구현의 AISkill.ObserveOnce와 AIBrain.ObserveExecution을 사용한다. 관측 key는 실행 중 한 번만 기록해 같은 상태로 매 프레임 요청하지 않는다.

## 적용한 변화

- 공격 45초 경과와 경로 탐색 세 번 실패는 관측으로 전달한다. 적이 살아 있고 공격 입력이 가능한 동안 선택을 유지한다.
- 벽 채굴의 6초 무변화와 60초 경과, 뿌리 채집의 25초 경과와 12초 무변화, 물체 부수기의 30초 경과와 5초 무변화도 같은 방식으로 전달한다.
- 부수기에서 피해가 보이지 않는다는 이유로 대상을 세션 영구 제외하거나 기억에 불가 대상으로 추가하는 처리를 제거했다. 실제 체력 관측은 남긴다.
- 터널의 30초 무진척과 전체 300초 경과는 관측으로 전달한다. 이미 완료된 대상·불가능해진 경로·실패한 하위 입력은 실제 결과로 전달한다. 실패한 하위 동작을 횟수 기준으로 자동 재시도하는 분기를 제거했다. 실제 실패 이유와 당시 위치·진척을 부모 결과로 전달해 AI가 재시도나 다른 행동을 고른다.
- 짧은 이동과 사거리 접근의 예상 시간 초과 및 0.25초 무진척은 관측으로 전달한다. 목적지 도착과 실제 대상 소실은 기존 결과다.
- 일반 이동의 구간 예산과 문 통과 포함 전체 예산 초과, 세 번 무진척을 관측으로 전달한다. 무진척만으로 앞 타일을 영구·시간제 차단하는 추론은 제거하고 실제 타일·물체의 경로 가능성을 다시 읽는다.
- 귀환 후퇴 60초 경과는 관측이다. 선택지에 명시된 목적지 도착과 적이 사라진 뒤의 종료 조건은 선택된 동작의 완료로 유지한다.
- 먹기 요청 뒤 3초가 지나도 수량 감소가 확인되지 않으면 소비 입력을 놓고 관측을 전달한다. 몸 동작은 수량을 계속 확인해 뒤늦은 실제 소비를 완료로 받아들이며, AI가 중단·전환할 수 있다. 같은 먹기 요청을 계속 누르거나 자동 반복해 중복 소비하지 않는다.

## 선택된 동작의 완료와 실제 실행 실패

한 번 타격·짧은 제자리 유지·3초 거리 벌리기처럼 선택지에 명시된 동작의 끝은 남긴다. 사라진 대상, 바뀐 무기 슬롯, 실제 경로 탐색 결과가 없거나 게임 입력이 거절된 경우도 원인과 함께 실행 결과를 반환한다. 미진행 시간을 이유로 유효한 목표와 사용자 부탁을 끝내는 정책은 공통 목표 계층에서 제거한다.

HitOnceLogic의 타이머 미확인 시 0.35초 입력 해제는 두 번 타격을 방지하는 동작이다. 시작 타격 미확인 1초와 시작 뒤 1초 fallback의 처리는 공통 구현 담당에게 별도로 전달했다. Core/AIRunGate는 이 변경의 파일 소유 범위 밖이다.

## 검증

`git diff --check`를 통과했다. 공유 worktree의 전체 모드 소스를 `dotnet build Tools/compile-check -c Release --no-restore`로 설치 게임 DLL에 대조해 경고 0·오류 0으로 빌드했다. 게임 실행과 외부 모델 호출은 수행하지 않았다. 실제 월드에서 타격·이동·소비의 지연과 AI 재판단이 이어지는지는 후속 실게임 검증 대상이다.

## 중첩 실행 단계 후속 보완

바깥 몸 동작보다 먼저 종료하던 Core/AIDoorPass, Core/AIBaseGuard.PickupStep, Core/AIPlaceGrid.PressStep도 보완했다. 각 출력의 observation 문자열로 문 열기·닫기 6초/전체 12초, 문 누름 2회, 물체 회수의 무피해 5초/수령 미확인 3초, 놓기 설 자리 3초를 전달하며 현재 phase와 입력을 유지한다. 실제 손에 들 수 없음과 지나가기 전에 문이 닫힌 상태는 실제 실행 불가 결과로 남긴다.

AIEdgeSkills, AIPickupSkill, AIPlace, AINavigator는 phase별 ObserveOnce로 관측을 전달한다. 완료 뒤 문 닫기 tail을 수행하는 AIEdge.Guard도 같은 관측을 phase별 한 번 전달한다. 누름이 이미 전송 중일 때 추가 누름을 만들지 않는 동기화는 유지한다.

기존 정책 실패를 기대한 회귀 17개를 현재 phase·입력 유지와 실제 관측 메시지를 확인하도록 바꿨다. 지연 수령이 같은 회수 동작의 완료로 연결되는 확인 1개를 추가했다. 정상 문 통과 420개 조합 등 기존 정상 실행 회귀를 포함한 전체 `dotnet run --project Tools/core-tests -c Release --no-restore` 결과는 **ALL CHECKS OK (1138)**이다. 이어 전체 모드 compile-check 경고 0·오류 0 및 diff check를 통과했다.
