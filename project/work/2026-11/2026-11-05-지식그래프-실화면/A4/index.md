# A-4 화면 기반 추정 문서

상태: A1·A2·A3 기반 A-4 작성 완료. 정본 5개 화면의 요소 ID에 연결했으며, 전체 제품 상태 전수 완료를 뜻하지 않는다.

이 문서 묶음은 2026-11-05 실제 화면 관측만으로 작성한 추정이다. 기존 기획 의도·제품 코드·기존 그래프를 읽지 않았다. 제품 방향이나 정책을 새로 정하지 않으며, 전체 제품 명세로 사용하지 않는다.

| 안정 ID | 타입 | 문서 |
|---|---|---|
| CKAI-CORE-01 | 제품코어 | [product-core.md](product-core.md) |
| CKAI-JOURNEY-01 | 유저저니 | [user-journey.md](user-journey.md) |
| CKAI-IA-01 | IA | [ia.md](ia.md) |
| CKAI-ACT-01 | 유저 활동 | [activity-observe-companion.md](activity-observe-companion.md) |

활동은 문제와 목표가 같은 한 가지 일, **AI 동료가 와 있는지와 무엇을 하는지 알아보기**로 묶었다. 메뉴 탐색, 채팅 열기, 명령 입력, 로그 읽기는 그 활동의 경로다. 키 조작별로 별도 활동을 만들지 않는다.

## 입력과 증거 경계

- A1: [화면 상태 목록](../A1/screen-states.md), [조작 기록](../A1/observations.json), [manifest](../A1/manifest.json).
- A3: [처음 온 사용자 기록](../A3/new-user.md).
- A2: [화면 목록](../A2/index.md), [정본 manifest](../A2/manifest.json), CKAI-01~04 및 CKHUD-01 화면설계서.
- `/ai` 제출과 응답은 A1만 관측했다. A3는 명령 문법을 발견하지 못했고 어떤 명령도 전송하지 않았다. 두 경로를 한 사용자의 연속 경험으로 합치지 않는다.
- A3의 플레이어 관리 진입은 A1에 없던 경로다. 추가 원본 [플레이어 관리](../A3/new-user-05-player-management.png)와 A2의 CKAI-04에 연결했다.
- 전체 게임 상태·지속 목표·가방·기억 조회/조작, AI 생성·삭제·on/off·목표 변경은 확인하지 않았다. 도움말의 `on|off|goal …`는 보인 문자열이며 실행 검증이 아니다.
- 네트워크·IPC·처리 함수와 정책 구현은 관측하지 않았다. 조작 기록의 `local help response` 표현만으로 로컬 처리라고 단정하지 않는다.

## 관측을 조직한 결과

이름표와 접속자 목록은 동료의 존재를 알아보는 단서, AI 로그는 최근 행동을 해석하는 단서, `/ai` 응답은 명시적인 AI 목록 단서로 정리했다. 명령 발견 실패, 플레이어 관리 우회, 로그 가독성, 스크롤에 따른 퀵슬롯 변경은 같은 활동의 막힘이다. 확인에 실패한 지속 목표를 달성 결과로 기록하지 않았다.

[manifest.json](manifest.json)은 문서의 안정 ID와 단계별 화면요소 연결을 옮긴 인덱스다. 의미의 원본은 위 문서이며, 다음 활동·기능·정책 연결은 새로 만들지 않았다. [validation.json](validation.json)은 요소 ID 존재 여부와 문서 파일 참조 확인 결과다.
