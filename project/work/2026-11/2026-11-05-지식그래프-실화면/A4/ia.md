# IA — 화면 기반 추정

- ID: `CKAI-IA-01`
- 관측 입구: 이미 실행 중인 월드. 최초 앱 진입이나 전체 게임 시작 화면은 미관측.
- 아래 화면 ID는 [A2 정본 manifest](../A2/manifest.json)와 대조했다. 화면마다 IA 묶음 하나를 부여한 화면 기반 추정이다.

| 화면 ID | 화면 이름 | IA 묶음 | 이 활동에서의 역할 |
|---|---|---|---|
| CKAI-01 | 월드 | 플레이 공간 | 이름표와 주변 캐릭터를 봄; 탐색 시작·복귀 |
| CKAI-02 | 채팅 | 채팅과 AI 안내 | AI 메시지를 읽고 입력칸을 통해 A1의 `/ai` 조회 수행 |
| CKAI-03 | 게임 메뉴 | 게임 관리 | 접속자 이름 확인, 플레이어 관리로 가는 분기 |
| CKAI-04 | 플레이어 관리 | 게임 관리 | 관리자·차단 목록을 보지만 AI 설명을 찾지 못한 우회 경로 |
| CKHUD-01 | 공통 HUD | 공통 표시 | 퀵슬롯 선택 변화와 복원을 확인하는 공통 표시 |

관측 동선은 월드에서 Return으로 채팅 입력 열기, 월드에서 Escape로 메뉴 열기, 입력이나 메뉴에서 Escape로 닫기다. 이는 UI 관측 기록이며 코드의 navigate 연결이나 모든 화면의 전역 단축키 정책을 선언하지 않는다. 모든 화면에서 공통으로 갈 수 있는 메뉴는 검증하지 않았다.

게임 메뉴에는 계속·버그/피드백 보고·플레이어 관리·설정·저장 후 종료가 보였다. 이 가운데 A3는 플레이어 관리 내부를 방문했지만 AI 설명/목표를 찾지 못했다. 나머지 하위 화면과 저장/종료 실행 결과는 미관측이다.

A3의 플레이어 관리 내부는 CKAI-04로 연결한다. 진입은 CKAI-03#7과 CKAI-03#12, 확인한 내용은 CKAI-04#2-1(관리자 Luminous)과 CKAI-04#3-1(차단 목록 빈 상태)이다. A1의 메뉴 표본에서는 해당 항목을 실행하지 않았으며, A3에서의 방문을 별도 근거로 사용한다.
