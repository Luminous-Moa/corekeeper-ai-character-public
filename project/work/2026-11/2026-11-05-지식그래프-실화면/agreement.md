# 지식그래프 실화면 후속 기준

사용자 요청: “코어키퍼 ai 작업 세션에 연결하고 지식그래프 개편 못했던거 이어서 해줘. 컴퓨터 유즈 이용 가능할거야.”

기존 개편에서 미룬 실제 게임 화면 탐색, 화면 원본·요소 위치 매칭, 처음 온 사용자 흐름과 코드·기능 연결 대조를 이어 한다. 기존 제작 기준은 ../2026-11-05-지식그래프-개편/agreement.md와 C:/Dev/_ref/head-agent-core/graph/build/02a-graph-definitions.md, 02b-graph-workflow.md다.

개발 지식그래프가 대상이며 게임 데이터 지식그래프·제품 기능 개편은 범위 밖이다. 기존 결정·인용·HTTP 증거를 보존한다. 그래프 기준 e82eb87과 실행 중 전투 시험판(기록상 76563bf)을 구별하고 코드 대조로 범위를 명시한다. 게임 월드·캐릭터 저장·설치본·전투 시험 정리는 이번 작업에서 변경하지 않는다. 기존 운영 상태를 보존하는 조회·화면 탐색을 우선하며, 상태 변경 없이는 확인할 수 없는 흐름은 한계를 남긴다.

컴퓨터 유즈로 Core Keeper 창과 실제 게임 화면, Claude 캐릭터·AI 행동 메시지를 확인했다. 최초 가려진 창 캡처는 다른 창이 찍혀 게임 근거에서 제외했고, 게임을 활성화한 뒤 다시 확인했다.

화면 탐색, 화면 문서 작성, 처음 온 사용자, 코드 대조, 통합 및 독립 검수의 역할을 제작 지침대로 분리한다. 결과는 이 폴더 아래에 두고, 원본 문서에서 그래프를 재생성한다. 실제 활동→화면요소→기능→코드/데이터→원문 조회의 대표 경로와 비대표 표본 대조로 완료를 판단한다. 아직 관측하지 못한 흐름은 관측 완료로 승격하지 않는다.
