# 채팅 폰트와 AI 정보 패널 흡수 — 합의

2026-11-06.

## 목적과 사용자 결정
- 기본 채팅창을 유지하면서 큰 한글 글자로 인한 불편을 줄이고, 작게 상주하는 별도 AI UI에서 AI별 스킬·장비를 조회한다.
- 기존 공개 모드의 재사용 가능성을 조사하고 가능하면 제작까지 진행한다.
- 사용자는 별도 모드 설치가 아니라 제작 중인 AI 모드에 기능을 흡수하는 것이 목표라고 명시했다. 외부 모드를 별도로 구독·설치하게 만드는 완료 방식은 목표와 맞지 않는다.
- 글꼴 적용 범위 질문에 사용자는 추천안을 수락했다: 채팅창과 새 AI 정보 패널에만 작은 한글 글꼴을 적용하고 게임 전체 UI 폰트는 유지한다.

## 보존 및 범위
- AI 발언은 기존 채팅에 남는다. 기존 입력·멘션·Tab·시스템 알림·7초 흐려짐 흐름을 보존한다.
- AI 정보 패널은 읽기 전용이다. AI 선택, 실제 스킬 레벨과 현재 착용 장비 조회를 제공한다. 특성 배분·장비 교체·추가 AI 판단 호출은 범위에 포함하지 않는다.
- 평소 작은 선택부, 선택할 때 상세를 펼치는 기본 흐름. 구체 레이아웃·기본 크기는 가독성과 기존 HUD 간섭을 기준으로 구현자가 정하고 실게임에서 판단한다.
- 호스트 사용을 현재 범위로 한다. 별도 원격 접속자 동기화는 포함하지 않는다.
- 재사용 조건이 확인된 코드와 폰트만 포함하며 해당 고지를 함께 배포한다. 허용 확인이 안 된 모드 코드를 가져오는 대신 현재 모드에 맞게 기능을 직접 구현한다.

## 실행과 완료 기준
- 시작점 현재 ai-character 902721e. 공통 트리의 SDK 설정·자료와 다른 대화 작업을 보존한다. 격리 작업 브랜치·worktree에서 구현한다.
- 상세 조사·설계·구현은 별도 작업자가 소유하고 HEAD는 위 합의와 완성 판단을 보존한다. 독립 코드 검수 뒤 대표 실제 흐름을 확인한다.
- 대표 흐름: 실제 한국어 AI 발언을 작은 채팅 글자로 읽음 → AI 선택 → 실제 스킬/착용 장비 조회 → 패널 닫기 → 기존 채팅 Enter·Tab 정상, UI 클릭이 공격·이동을 일으키지 않음.
- 필요한 오프라인 관문과 Unity 컴파일, 실게임의 글자/줄간격/배치/상태 갱신 확인을 수행한다. 시험 환경·게임 사용은 기존 동시 작업과 조율한다.
- 기존 프로젝트의 최종 병합·원격 push 승인 조건을 유지한다. 먼저 제작·검수·실게임 확인을 끝내 구체 결과를 제시한다.

## 2026-11-06 실제 화면 확인 중 사용자 정정
- 사용자는 더 작아야 하는 대상이 새 AI 패널이 아니라 기본 채팅창 글자라고 명확히 했다. 동봉 글꼴12→10px의 약17% 축소만으로는 목표를 충족하지 않는다. 과거 합의의 원본 약절반 크기를 참고해 기본 채팅 동작은 유지하며 더 작고 선명한 표시 경로를 구현한다. 새 패널 자체 가독성 개선(정수배율)은 별개로 유지한다.
- 사용자는 현재 게임을 직접 조작 중이라고 확인했다. 자동 UI 입력·게임 종료·설치/복원은 사용자와 다시 조율하기 전 보류하며, 코드 작업과 읽기 전용 조사는 계속한다.
- 사용자가 제미나이가 장비를 입었는데 패널에 제대로 표시되지 않는다고 보고했다. 실제 손 장비 갱신만 확인한 중간 결과는 착용 장비 전체 정확성의 증거가 아니다. 방어구/장비의 실제 상태와 UI 불일치를 해결하고 재검증해야 완료다.

## 범위 최종 확인
- 사용자: 방어구 착용 등 선택지 관련은 별도로 작업한다.
- 이번 작업은 채팅 글자 축소와 실제 상태를 정확히 보여주는 읽기 전용 AI 정보 UI로 한정한다. AI 자동착용·행동 후보/선택지·전투 정책은 추가하지 않는다.
