기존 자료에 있던 ‘게임 화면 사용자 유예’는 당시 작업 범위의 기록으로 보존한다. 이번 후속에서 확보한 5화면과 CKAI-ACT-01에만 새 관측을 붙인다. 모든 유예가 해소됐다고 일괄 덮어쓰지 않는다. 기존 HTTP C3 결과도 이번 게임 C3와 별도로 유지한다.

화면설계서 전체·그림·코드 상세는 활동 사용자 본문과 C3 입력에서 생략하고 A2/B 정본으로 연결했다. 이는 정보 삭제가 아닌 역할 분리다. 기존 코어 의도와 행동 정책은 이번 일부 관측으로 재작성하지 않았다.
