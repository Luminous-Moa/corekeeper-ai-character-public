# Core Keeper AI 캐릭터 — Jev 행동 설계 독립 검토

검토일: 2026-11-03
대상: `2026-11-03-jev-행동설계.md`
범위: 사용자에게 제시할 중간 해상도 설계의 주 흐름, 역할 경계, 비동기 판단과 정보 전달의 일관성. 코드 구현·실게임·API 호출·외부 자료의 사실 재검증은 수행하지 않았다.

## 판단

**사용자 제시 전에 반드시 수정해야 할 중요한 문제는 발견하지 못했다.** 사용자 의도에 없는 전술 폴백도 발견하지 못했다. 다음 판단은 설계 문서의 일관성에 대한 것이며 실행 가능성이나 성능을 검증했다는 뜻이 아니다.

- **주 흐름이 연결된다.** 목표 생성부터 탐색·발견·채굴·전투·철수·귀환·결과 보고까지 사건과 상태가 이어진다. 철수 없는 경우의 작업 재개와 철수로 보류된 수집 목표의 처리도 구분한다.
- **역할 경계가 유지된다.** LLM은 전체 목표와 지식을, Jev는 구체적 행동과 전투 판단을, 프로그램은 가능한 후보 구성·관찰·실행을 담당한다. 명시적 제약과 물리적 실행 조건으로 후보를 제한하는 것과 프로그램이 전술적 유불리를 판단하는 것을 구분한다. 자동 회피·자동 후퇴·자동 대상 전환은 기본안에 들어 있지 않다.
- **호출 억제와 전투 갱신이 양립한다.** 관찰과 후보 갱신은 계속하고, 평상시에는 의미 있는 사건에 호출한다. 전투에서는 최신 상태로 다음 요청을 구성하되 같은 결정을 유지할 수 있을 때만 쉰다. 프로그램의 사건 감지가 곧 후퇴 등의 전술 선택이 되지는 않는다.
- **목표 변경과 늦은 응답 처리에 중요한 모순이 없다.** 목표 수정 번호와 현재 실행 조건을 함께 확인한다. LLM의 철수 지시는 기존 목표의 늦은 Jev 응답을 차단하고 충돌 동작을 중단한다. LLM 자신에게도 오래된 판단을 거르는 원칙을 적용한다.
- **단일 요청과 행동 연속성의 대가가 드러나 있다.** 목표 변경 시에도 취소 완료·응답·타임아웃까지 기다린 뒤 새 요청을 보내므로 새 철수 행동이 즉시 시작된다는 보장은 없다. 문서는 그 공백을 프로그램 전술로 메우지 않으며, 유효한 기존 행동만 이어 가고 필요하면 멈춘다고 명시한다. 이는 숨은 폴백이나 모순이 아니라 기본 설계의 지연 한계다. 같은 행동·대상의 재선택 시 재시작하지 않는 규칙도 연결된다.
- **정보 전달의 경로가 명시돼 있다.** LLM의 지식 선별, 프로그램의 대상별 사실 조회, 최신 관찰, 직전 선택과 결과가 Jev 입력으로 이어진다. 저장소와 모델 기억을 혼동하지 않고, 없는 지식은 모름으로 전달하며 비동기 보충 때문에 전투 전체가 기다리지 않는다.

## 제안과 사실의 구분

문서는 구성·중단 규칙·정보 형식을 아직 확정하지 않은 제안으로 명시한다. 기존 성향값 방식의 잠정 방향을 별도로 남기고, 현재 몸의 실게임 검증이 미완료임을 밝힌다. 대표 흐름 표는 실행 결과가 아닌 설계상 사건 추적이며, 외부 사례의 응답 시간도 Core Keeper 성능 보장과 분리한다. 이 검토 역시 기존 기록과 외부 수치 자체를 독립 실측하거나 재검증한 것은 아니다.

현 단계에서는 추가적인 세부 구현 계약을 요구하지 않고 설계안으로 제시할 수 있다. 다음 판단을 실제로 바꿀 증거는 문서 9절의 몸·관찰·중단 가능성 확인과 전투 중 지연 실측이다.
