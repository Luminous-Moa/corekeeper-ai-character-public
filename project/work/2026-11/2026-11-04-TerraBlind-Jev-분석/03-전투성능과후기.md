# TerraBlind 전투 성능과 공개 후기

2026-11-04 공개 검색 기준. **제작자가 보스전 성공 시연으로 소개한 영상은 공개돼 있지만, 제삼자가 직접 설치해 반복 전투 결과를 보고한 후기는 이번 검색에서 확인하지 못했다.** 따라서 이 프로젝트는 구체적인 구현 참고 사례로 활용할 수 있으나, 다양한 환경에서의 전투 안정성이 실사용자들에 의해 입증됐다고 평가할 수는 없다.

## 혼동하면 안 되는 두 시연

README에는 서로 다른 흐름이 함께 소개된다.

1. **Jev가 판단하는 보스전 시연**: 마스터 모드 하드모드 이전 보스 처치라는 제작자의 설명.
2. **새 월드에서 Wall of Flesh까지 가는 코드 전용 진행**: 수작업으로 연결한 자동 진행 절차. README는 이 경로에 DragonLens의 무적·몬스터 생성 중지 등이 필요하다고 밝힌다. 무한 목재, 상시 버프 등 진행 보조도 설명한다.

두 번째의 14분15초·3배속 완주를 첫 번째의 보통 조건 전투 능력 근거로 쓰면 안 된다. 반대로 두 번째의 무적 설정을 근거로 첫 번째 보스전 영상도 무적이었다고 결론 낼 수 없다. 적용 범위를 각각 확인해야 한다. [두 시연과 조건을 함께 설명한 원문](https://github.com/Reisenbug/TerraBlind/blob/0859ca29aedea7bb48324c68eaece35b629c6d37/README.md)

## 현재 코드와 영상 버전도 다르다

이번 코드 분석은 `0859ca29aedea7bb48324c68eaece35b629c6d37`에 고정했다. README와 외부 소개에는 이전의 9가지 의도 또는 수평·수직 두 질문 방식이 남아 있지만, 이 버전의 보스 제어는 가능한 구체 행동 하나를 `action` 질문으로 고른다. 그러므로 9월 공개 영상의 성공을 현재 후보 구성·필터·실행 방식의 검증 결과로 그대로 사용할 수 없다. 상세 차이는 [전투 분석](01-전투.md)에 정리했다.

## 지금 내릴 수 있는 평가

- **구현의 구체성**: 실제 게임 상태를 읽고 후보를 생성해 Jev에 보내는 코드가 연결돼 있다. 단순한 개념 소개는 아니다.
- **전투 성공 가능성**: 제작자가 성공 시연을 공개한 사례가 있다. 시연 조건·실패 시도 수·현재 버전과의 일치 여부를 확인하지 않고 보편적인 승률로 환산할 수 없다.
- **일반 환경 안정성**: 장비·보스·지형·네트워크 지연을 바꾼 독립 반복 시험이 필요하다. 현재 공개 후기만으로는 결론을 내릴 수 없다.
- **코어키퍼에 대한 함의**: 어떤 정보를 어떤 후보와 연결하는지 참고할 가치는 크다. 그 구조를 옮기면 전투를 잘하게 된다는 결과 보장은 아니다.

실제로 성능을 비교할 때에는 보스와 장비·회복품·경기장·보조 모드·모델 버전·반응 지연을 고정하고, 여러 차례의 승패·피해량·회복 소모·처치 시간·선택과 실제 실행의 차이를 함께 기록해야 한다. 이는 이번에 시행한 실험이 아니라, 앞으로 시연 주장과 반복 가능한 성능을 구분할 기준이다.

## 설정 부담이 후기를 줄였을 가능성

사용자 설정이 필요한 구조이므로 진입장벽은 후기 부족을 설명할 수 있는 가설이다. 다만 방문자·다운로드·설정 완료·실제 플레이의 단계별 수치가 없어 주원인으로 확정할 수는 없다. 기능별 필요 조건도 구분해야 한다.

| 사용하려는 기능 | 확인한 설정 조건 |
|---|---|
| 기본 모드 설치 | Terraria·tModLoader 환경과 완전한 `.tmod` 필요 |
| 자연어 에이전트 기본 경로 | 로컬 Codex CLI와 로그인. 모드가 처음 작업을 받을 때 프로세스를 시작 |
| 자연어 에이전트 대체 경로 | Codex 사용을 끄고 호환 LLM 서비스의 API 키·주소·도구 호출 지원 모델을 설정 |
| Jev 보스 제어 | 별도 TypeSafe/Jev 키와 전투 제어·공격·회피 허가. 자연어 에이전트와 별개의 제어 경로 |
| Jev 벌목 | 현재 실행 경로는 모드 설정의 TypeSafe 키를 요구 |

자연어 에이전트는 Codex의 기존 로컬 인증을 쓰며, 그 인증은 ChatGPT 계정 또는 API 인증일 수 있다. 일반 LLM API 경로도 제공하므로 특정 구독 계정만이 유일한 진입로는 아니다. Claude Code 설치는 확인한 기본 실행 경로의 필수 조건이 아니다. [에이전트 설정 문서](https://github.com/Reisenbug/TerraBlind/blob/0859ca29aedea7bb48324c68eaece35b629c6d37/Agent/README.md#L1-L17)

그럼에도 일반적인 모드보다 추가로 이해할 요소가 많다. 계정 또는 API 인증, 서로 다른 LLM과 Jev 설정, 모델·서비스별 사용량과 비용 확인, 연결 실패 시 원인 구분이 필요하다. AI 도구를 이미 사용하는 사람에게 익숙한 과정도 일반 게임 이용자에게는 사용을 포기할 이유가 될 수 있다. 이는 설정 구조에서 도출한 해석이며, 실제 이탈 사용자를 조사한 결과는 아니다.

따라서 적절한 결론은 **설정 부담이 잠재 사용자를 줄였을 가능성이 있고, 후기 수만으로 모드의 재미나 전투 능력을 판단하기 어렵다**는 것이다. ‘Codex/Claude Code 사용자가 아니면 시도할 수 없다’거나 ‘후기가 적은 원인은 반드시 진입장벽이다’까지 확장할 근거는 없다. 프로젝트 노출 규모와 후기 작성률, 검색되지 않는 커뮤니티 사용도 별개 변수다.
