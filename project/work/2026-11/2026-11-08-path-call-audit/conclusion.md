# 길 계산 호출 폭증 — 코드 분석 결론

2026-11-08. 사용자 질문은 길 계산이 왜 그렇게 많은지 코드에서 문제를 파악하는 것이다. 소스 수정·게임 재현·설정 변경은 하지 않았다.

## 핵심 판단

후보마다 독립적으로 길을 계산하고, 이미 계산한 길을 후처리에서 다시 요청하며, 작은 캐시를 통째로 비우는 구조가 겹쳤다. 모든 후보를 보존한다는 기존 제품 합의와, 모든 후보의 길을 중복해서 한 프레임에 계산한다는 구현은 구분해야 한다.

## 707회와2179개는 서로 다른 수치

첫 하위 요청 로그의707회는 실제 PlanC호출 수다. 후보 생성357회와 최종 채굴후보350개의 위험 설명을 위한 재요청350회가 합쳐진다.

| 요청 발생 지점 | 횟수 |
|---|---:|
| 보이는 벽 채굴 후보 | 330 |
| 갇힌 Mushroom2개 × 사방 접근위치4곳 | 8 |
| 기억 광석19곳 평가(성공18곳) | 19 |
| 생성 합계 | 357 |
| 최종 dig후보330+2+18개 위험 설명에서 경로 재요청 | 350 |
| 합계 | 707 |

실제 로그의n707/cached0/tunnel707과 일치한다. 이 중707개가 모두 서로 다른 목적지라는 뜻은 아니다.

반면2179는 재시도 때 등장한 탐험 지점 수다. 처음 탐험 경계 작업은 진행 중이라 결과가0개였고, 여러 프레임에 걸친 검색이 완료된 뒤2179개 목적지가 제공됐다. 첫707회에는 이 탐험 결과가 포함되지 않았다. 따라서707→2179를 같은 목록의 크기 변화로 해석하면 안 된다.

## 구체적인 코드 문제

1. **결과를 만들고 버린 뒤 설명용으로 다시 검색한다.** 후보 생성에서 경로·비용을 이미 구했지만, 위험 설명 후처리가 다시PlanC를 호출한다. 후보 준비 동안 원래 계산 결과를 보존해 설명을 만들 수 있다.
2. **캐시가 현재 처리 규모보다 작고 전체 삭제 방식이다.**64개를 초과하면 전부Clear해 앞에서 계산한 결과가 후처리에 남지 않는다. 같은2179지점 목록을 두 번 순회한 기존 오프라인 재생에서도 두번째2179miss/0hit다. 용량만 늘려도 최초 탐색 총량은 줄지 않는다.
3. **같은 출발점의 목적지마다 전체 탐색을 새로 시작한다.** 현행Find는 누적비용으로 확장하는Dijkstra식 탐색이며, 목적지마다탐색큐·거리·이전노드 및타일비용조회상태를 새로 만든다. 가까운 목적지끼리 공유되는 영역도 반복 탐색한다. 여러 목적지의 탐색을 공유할 여지가 있다. 다만 목적지 타일에만 적용되는 예외가 있어 단순히한번의공통검색으로치환하면의미가달라질수있다.
4. **증분 경계 검색 뒤의 실제 경로 평가는 한 번에 몰린다.** 경계 지점을 찾는 작업은 프레임별로 나누지만, 완성된2179지점을foreach로돌며PlanC하는부분은동기다. 탐험 검색을분할했다는사실만으로이12초구간이분할되지는않는다.
5. **실패 재시도가 비싼 준비를 다시 실행한다.**HTTP400 뒤 재시도는 후보준비전체로돌아간다. 관측/목표가그대로인범위에서도재사용계층이부족하며, 그사이에완성된대규모탐험결과까지합쳐져비용이커진다. 400의원문이없어상세요청오류는별도미확정이다.

## 의도된 동작과 구분

[제약 해제 합의](../2026-11-07-제약해제/00-agreement.md)는 목표/허기 기반 후보 숨김과 탐험 대표지점 압축을 제거하도록 정했다. give목표에도탐험을열어두고모든알려진목적지를노출하는것을그자체로버그라고결론내리지않는다. 문제는그선택지를지원하는계산의재사용과스케줄링이규모에맞지않는것이다.

## 수정 방향

- 우선 후보준비1회 안에서 경로결과를 유지하고후처리가그결과를읽게한다. 장기캐시는전체삭제대신교체정책과입력변경무효화를사용한다.
- 경로평가내부까지중단후이어가기와모든AI합산프레임예산을도입한다. 캐시수정과별개로최초계산때의긴멈춤을막아야한다.
- 같은관측·출발점의여러목적지를평가할때공통탐색을재사용하도록검토한다. 목적지예외·도구·장애물·기억조건을보존하는것이전제다.
- 실패재시도에서재사용가능한준비결과와변경된정보를구분하고, HTTP400원문을비밀값없이기록한다.
- 후보수상한이나목표별숨김을임의로복원하지않는다. 기존선택권을보존하면서불필요한계산을없애는것이이번분석에맞는방향이다.
