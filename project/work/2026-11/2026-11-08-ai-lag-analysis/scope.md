# AI 통신 시 화면 끊김 분석 범위

- 문제: AI와 통신할 때 화면 전체와 사용자 캐릭터가 순간 멈춘다.
- 목표: 최신 설치판의 AI 요청 전후 경로와 실제 실행 자료를 대조하여 원인, 확실성, 해결 우선순위를 제시한다.
- 범위: 읽기 중심 원인 분석과 해결책 제안. 코드 수정, 서비스 재시작, 게임 조작, 설치 변경은 이번 요청에 포함되지 않는다.
- 기존 자료: [11월 6일 진단](../2026-11-06-stutter-diagnosis.md)을 재사용한다. 과거 측정은 현재 사용자 장면의 재현값과 구분한다.
- 기준: API 대기와 게임 메인 스레드 계산을 구분하고, 실제 측정과 코드상 가능성을 구별한다. 판단 내용·기억·명령 의미를 보존하는 해결책을 우선 제시한다.
