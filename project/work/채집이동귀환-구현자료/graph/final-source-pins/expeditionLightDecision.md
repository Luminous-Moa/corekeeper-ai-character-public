# 채집·이동·귀환: 조명 시야 후속 분리

사용자 결정: “조명 시야는 후속으로 분리”.

직전 제시한 선택지 중 이번 행동 구현은 기존 화면 범위 시야로 완성하고, 조명까지 사람과 같은 시야를 구현하는 일은 별도 후속으로 분리하는 선택이다. [기존 확정 합의](2026-11-07-채집이동귀환-확정합의.md)의 이번 구현 범위를 이 결정으로 조정한다.

- 이번 수용 범위는 `7af8f91e5d26e4fd9ce5996809ae41e213340118`의 채집·이동·귀환 구현과 기존 화면 범위 관측이다. 조명·어둠의 실제 사람 시야 동일성을 완료로 주장하지 않는다.
- [독립 검수](../채집이동귀환-구현자료/review.md)의 R1은 해결된 결함이 아니라 사용자가 후속으로 분리한 항목이다. R2~R7 수정과 오프라인 생산 경로 및 Unity 컴파일 수용 근거는 그대로 사용한다.
- 본 소스 통합과 목적·합의→코드→검증의 개발 지식그래프 반영을 진행한다. 같은 코드에 대한 완료된 구현 검수를 반복하지 않는다.
- AI별 실제 조명 확보 방법과 후속 검증 범위는 [조사](../채집이동귀환-구현자료/vision-authority-investigation.md)를 출발 자료로 다시 정한다. 이번 결정은 CPU 근사 시야나 오프스크린 렌더 구조를 확정하지 않는다.
- 설치·실게임·외부 모델 시험은 기존의 치트 환경 구축 후 통합 검증 방침을 유지한다.
