## 1. 선택 트리와 직접 실행 병행

- 눈앞의 채집물 묶음, 현재 이동 계속, 이미 정해진 목적지 이동 등 구체 행동은 바로 선택한다.
- 다른 대상·장소를 찾아볼 때는 얕은 분류 트리를 펼쳐 좁힌다. 상위가 이미 정한 품목·장소를 다시 고르게 하지 않고 현장에 맡긴 부분을 선택한다.
- 메뉴 탐색·뒤로 가기 중에도 유효한 현재 행동을 이어 간다. 메뉴 취소와 몸 행동 중단·부탁 취소를 구별한다.
- 목표 외 자원도 관측·지식 공개 범위 안에서 보여주고, 원래 부탁·급한 정도·추가 행동의 비용을 함께 제공한다. 구체 분류와 순서는 실제 후보를 확인해 구현에서 정한다.

## 2. 곁일은 판단모델에 위임

- 곁일 여부와 범위는 판단모델에게 맡긴다. 코드가 고정 비율·개수·시간으로 곁일 허용량이나 정답을 대신 정하지 않는다.
- 원래 부탁·현재 작업·진척을 유지하고, 급한 정도·지금까지의 지연·가방 여유·위험·재방문 비용을 판단할 수 있게 한다.
- 선택한 곁일 묶음은 끝이 있는 실행으로 처리한다. 새로 발견한 대상은 기존 묶음에 자동 추가하지 않고 다음 판단에 제공한다. 곁일 뒤 원작업을 이어 갈 맥락을 보존한다.
- 기존 상위 계획과 현장 판단의 역할 구분을 유지한다. 새 지역 탐험·조달처 변경처럼 계획을 크게 바꾸는 선택은 상위 재계획과 연결한다. 이 항목을 임의의 곁일 제한을 추가하는 근거로 사용하지 않는다.

## 3. 목표량·귀환·후속 작업 연결

- 사용자에 따르면 30개 등 임의 수량 제한은 다른 작업에서 해제 중이다. 이 작업은 해당 해제를 중복 구현하지 않고 변경 결과와 연결한다. 현재 제거 완료를 확인했다는 뜻은 아니다.
- 원정 전체 목표량과 현장 실행 묶음을 분리한다. 상위는 부탁과 실제 여건에 맞춰 목표량·귀환 조건·다음 작업을 함께 계획한다.
- 여러 묶음의 실제 확보량을 누적한다. 단순 목표량 도달과 사용자가 명시한 엄격한 상한을 구별하며, 목표량 도달 자체로 자동 종료·귀환하지 않는다.
- 운반 여유·도구 상태·위험 때문에 목표 전에 귀환하면 부족량과 재개할 일을 남긴다.
- 귀환 목적을 도착 뒤 작업까지 연결한다. 보관이면 보관, 강화 후 재개이면 강화와 원작업 재개를 이어 간다. 도착·단계 완료·원래 부탁 완료는 구별한다.
- 귀환 선택 후 위험에 대응할 수 있다. 새 광맥 때문에 귀환을 늦추려면 계획을 다시 판단하며, 발견만으로 귀환을 자동 연장하지 않는다.
- 원정은 새 목표 계층이 아니라 이번 외출의 목적·재량·귀환·후속 작업을 함께 계획하는 단위다.

## 4. 선행 질문과 채집 묶음

- 사람 시야 원칙과 기존 다음 갈림길 방향 선행 질의 예외를 유지한다. 응답 시간을 확보하도록 미리 질문하고, 늦으면 미선택 갈래로 들어가지 않는다. 응답은 실행 시점에 재검증한다.
- 선행 질문의 구체 거리는 실제 이동 속도와 응답 시간을 기준으로 구현·검증에서 조정한다. 이번 합의에서 고정 수치를 정하지 않는다.
- 선택 당시 보이는 같은 종류의 자연스럽게 모인 대상을 묶는다. 벽 광맥·식물·바닥 아이템의 배치와 실행 방식에 맞춰 종류별 판정을 정한다.
