# 통합 소스·검증판 수용 판단

HEAD 판단. 대상은 `39b22df96dffe869ab0ccd474b18d31462b71d70`이며, 수용 범위는 **구현 소스·오프라인 연결 흐름·Unity 컴파일·설치 없는 SDK 후보 패키지**다. 실제 모델 판단·게임 소비자·설치 후 성공은 아직 수용하지 않는다.

## 합의와 결과

- [트리 합의](tree-agreement.md)의 분류 → 실제 보유 물품 → 조작 → 필요한 인자 → 실행, 뒤로·선택 전체 취소와 원래 부탁/몸 동작 보존이 실제 소스와 연결 흐름에서 확인됐다.
- 가방 분류·물품·조작에는 임의 숫자 자르기와 페이지가 없고, 전체 및 생성 단계의 현장 후보 누락 상한을 제거했다. 물리 관측·실행 가능성·권한과 기존 호출 예산은 보존했다.
- [통합 합의](integration-agreement.md)에 따라 최신 공식 c4 생활 트리의 손실 없는 페이지·알려진 대상 직접 실행·작업 수량·진행 중 실행 바인딩을 보존했다. 서로 다른 소비자의 계약을 하나로 덮지 않았다.
- 독립 검수에서 찾은 이전 가방 반례, 실제 상자 용량, 프리셋 역할 변경 복구, 생활 메뉴의 전투 보류 시 가방 진입과 표시 복귀 뒤 오래된 진입 응답 거절을 수정·재현했다. 늦은 닫힌 가방 leaf가 실제 조작을 시작하지 않는 것도 확인했다.
- [통합 보고서](integration-report.md), [독립 통합 검수](review-integrated.md)와 연결 근거는 실제 제품 소스를 실행하되 World/소비자·입력 경계 일부는 로컬 대체임을 구분한다. 독립 최신 경계는 199/199이며 과거 판의 성공으로 새 판을 대신하지 않았다.
- Unity와 정상 SDK export는 최종 소스·입력·출력 해시로 대응했다. 배포 후보는 C# 소스와 manifest인 표준 SDK payload이며 검증용 compiler DLL을 설치 파일로 혼동하지 않는다. 기존 공식 소스·설치의 불변도 기록됐다.

## 공식 소스 반영 판단

현재 공식 ai-character c4가 최종 통합판의 조상이며, c4와 최종판 사이 차이는 제품 C#·메타 및 관련 테스트다. 실행 bridge의 brief/protocol이나 설치·환경 설정을 바꾸는 diff는 없다. 공식 작업 폴더의 기존 환경 수정·미추적 파일을 보존한 채 `--ff-only`로 로컬 소스 반영하는 것을 승인한다.

반영 직전 최신 HEAD·상태·대상을 다시 읽는다. c4와 다르거나 관련 파일에 새 미커밋 작업이 생겼으면 추정 덮어쓰기·reset을 하지 않고 차이를 HEAD로 돌린다. 설치·프로세스 재시작·게임·외부 모델·공개 배포는 이 판단에 포함되지 않는다.

공식 지식그래프 반영은 최종 staging의 독립 출처/경로 검수와 최신 입력 드리프트 확인 후 관련 원본 패치·재생성으로 수행한다. 기존 기획·생활·release 목표와 기록을 보존하고 중간 사본의 history/context를 역복사하지 않는다.

## 남은 실제 소비자 검증

[실게임 준비안](integration-runtime-plan.md)의 별도 시험 월드/플레이어·변경 전 백업·bridge 버전 정렬과 기존 비용 한도 안에서 실제 자연어 → 모델 선택 → 게임 조작 → 관측 → 원래 부탁 계속하기를 확인해야 한다. 기존 실게임·외부 모델·설치 보류가 해제되기 전에는 실행하지 않는다. 이 검증 전 전체 사용자 플레이 결과를 완료로 선언하지 않는다.
