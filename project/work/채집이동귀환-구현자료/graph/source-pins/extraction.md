# 검수된 행동 규칙의 전체 대상 추출 결과

검수된 행동 수집 방식을 고정 원본 3,235개 source 전체에 적용했다. Terra 네 담당자가 추출기를 작성·실행했고 별도 컨텍스트에서 각 그룹을 검수했다. 필수 지적 수정과 재검수를 포함해 A/B/C/D 모두 통과했다.

새 추출본은 967개 서로 다른 source에 연결된 1,432행이다. `code_linked` 1,345행과 원본 레시피 설정 `asset_link` 87행을 구분한다. 요리 재료 81개의 순서쌍 6,561개는 별도 결과 관계표다. 같은 source에 서로 다른 행동이 연결될 수 있으므로 행 수는 객체 수가 아니다.

## 산출물 진입점

- [통합 보고서](package/report.md): 파일 구성·집계·검수 상태·재생성 명령.
- [통합 collection](package/collection.json): 그룹별 payload를 변형 없이 보존한 결과.
- [근거 manifest](package/manifest.json): 원본 추출·coverage·요리 관계표·검수 및 근거 파일의 경로와 SHA-256.
- [패키지 검증 결과](package/validation.json): 참조·source·규칙·집계 검사.
- [요리 6,561쌍](D-outcomes/cooking-pairs.json).

이 묶음은 주변 근거 파일을 참조한다. `package` 폴더만 다른 곳으로 옮기면 참조가 분리되므로 manifest에 있는 파일 관계를 함께 유지해야 한다.

## 전수 적용과 검증

네 그룹은 같은 source 집합 3,235개를 검사하고 규칙별로 적용·비적용·판단 불가를 분리했다. source가 같아도 변형·프리팹 원본이 다르면 임의로 합치지 않았다. 고정 입력·코드 해시, 참조, 중복, 64비트 주소 문자열을 확인하고 별도 폴더에서 반복 재생성했다.

독립 검수에서 표본과 다른 좌석/문 설정, 안장 교체, 축종별 먹이 태그, 수리 비용, 최대 레벨 거절, 웨이포인트 상속, 상자의 실제 변환 수량, 자판기 가격, 인벤토리 사용 상속과 요리 계산을 대조했다. 요리 6,561쌍은 추출기의 계산 함수를 재사용하지 않은 독립 정수 상태·IEEE float 계산과 전부 일치했다. 레시피 1,352항목도 직접 설정과 1단계 상속 원본에 대조했다.

중요 수정은 최대 레벨 거절을 미결로 분류한 오류, 포털 코드를 상속하는 웨이포인트 누락, 상자의 직렬화 수량과 실제 Converter가 쓰는 초기값의 혼동이다. 기존 표본의 상수를 다른 대상에 그대로 복사하지 않았다.

## 무엇이 여전히 미결인가

각 `coverage.json`과 검수 문서는 개별 source의 이유를 보존한다. 다음은 중요한 경계다.

- A: 문 6개, 전기 장치 21개의 다른 구성·장면 override 등은 해당 검수 규칙으로 확정하지 않았다. 임의 회로의 부하 결과와 배의 전체 조종/안전 하선까지 검증한 것은 아니다.
- B: 2406:0의 catalog prefab과 자기 authoringRef 차이를 원본 연결 예외로 유지했다. 추가 loader/모드 및 동적 변형의 실제 선택은 별도 조건이다.
- C: 다른 포함/근접 반응·AF 자판기 등 별도 처리 경로를 후보로 남겼다. 압력판은 적격 충돌 후보가 공급된 경우의 상태·전력 변화이며 플레이어의 최종 베이크 충돌 필터는 미결이다.
- D: 다른 UI·자동 제작 유형은 검수된 소비자와 구분했다. None 설정 99개를 실제 제품 레시피로 세지 않았고, allowCraftingNone 특수 7개와 nonzero 제품 4600의 원본 부재는 별도 미결이다. 포획의 모든 미래 tick 재요청 가능성도 확정하지 않았다.
- 모든 결과는 정적 코드·원본 연결이다. 실제 월드 DB·승인·타이머·네트워크·엔티티/파일 성공은 관측하지 않았다.

따라서 원본 전체에 검수된 규칙을 적용한 결과이며 **게임의 모든 가능한 행동을 전수 발견했다는 뜻은 아니다.** 수집되지 않은 행위를 곧바로 불가능하다고 판정해서는 안 된다.

## 기존 자료와의 관계

기존 `게임원본-상호작용/raw`, `final/collection.json`, 지식그래프, 모드·게임·세이브는 변경하지 않았다. 이번 산출물은 원본 근거와 재현 스크립트를 갖춘 별도 보강 추출본이다. 이후 그래프에 반영할 때도 source 신원, 조건, 정적 근거 수준 및 미결 경계를 함께 유지해야 한다.
