# 개발 방향 판단

[개발 방향](01-direction.md)을 승인한다. 수량 조합을 열거하지 않고 상위 계획의 작업량을 쓰며, 현장은 트리에서 대상·재료·시설을 좁혀 실행한다. 탐색은 읽기 전용으로 현재 행동과 대기 선택을 보존하고 직접 실행과 같은 실행/재검증 입구로 연결한다.

첫 구현 단위는 공통 트리와 제작·요리·농사·보관/꺼내기의 실제 선택 확대이다. 전체 시설 기능 완료로 보고하지 않는다. 수리·자동 가공·강화·거래·낚시의 새 몸 실행은 개발 방향의 후속 단위로 유지한다. 기존 가방장비 구현을 별도로 복제하지 않는다.

가방장비 후보는 공식 코드로 간주하지 않고 격리 생활 worktree의 통합 기반으로 사용해 이번 연결을 검증한다. 독립 의존 조사에서 77484ec의 가득 찬 상자 여유 공간 판정 문제가 확인됐고, 1fc89b93edbee31a9001a174581e32568119efc1에서 수정·어댑터 67/0 확인이 있으므로 통합 기반은 이 커밋으로 고정한다. 이 추가 수정 뒤 Unity 컴파일은 아직 확인되지 않았으므로 이번 통합 후보에서 수행한다. 가방장비 담당 worktree와 공식 저장소의 미커밋 상태는 보존한다. 선택·결과 계약을 실제로 연결한 후보를 만들고 대표 오프라인 실행/회귀/Unity 컴파일과 독립 검수 뒤 반영 상태를 보고한다. 기존 설치·실게임 보류는 유지한다.

명세에는 상위 수량/범위의 전달과 현장 선택의 충돌 처리, 다른 작업 실행의 진척을 원래 목표에 잘못 합산하지 않는 조건, 실행 후 결과와 실제 가방 확보의 차이를 명시한다. 사용자 소유의 새 정책을 추가하지 않는다.
