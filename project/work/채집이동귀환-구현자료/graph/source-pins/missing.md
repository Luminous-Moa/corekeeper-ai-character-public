# 필요한 행동의 누락 — 통합 판단

2026-11-06. 본 코드 ai-character b25099f 기준. 사용자 요청은 장비 보관·버리기를 포함해 필요한데 없는 행동을 찾는 조사이며, 코드·게임·설치·정책은 바꾸지 않았다. 사용자의 직접 플레이에 개입하지 않았다.

## 결론

앞선 선택지 품질 검토는 이미 생성되는 후보의 정확성에 집중했고 행동 범위의 충분성을 보증하지 않았다. 현행 봇은 필요한 물건을 챙기고, 원하는 장비로 바꾸고, 쓰던 물건을 정리·유지하는 생활 흐름에 중요한 공백이 있다. 실행 기술 자체가 없는 경우와 자동/특수 상황에서만 가능한 기술을 일반 목표로 부를 수 없는 경우가 섞여 있다.

## 방어구 질문에 대한 답

이미 가방에 있는 방어구를 골라 착용·해제·교체하는 목표·후보·실행은 없다. 제작물 커서 정리와 바닥 물건 습득에는 게임의 빈 전용 슬롯 자동 배치 경로가 있으나 항상 장착되는 것이 아니다. 따라서 방어구를 전혀 못 입는다는 결론도, 스스로 가진 방어구를 선택해 갈아입는다는 결론도 맞지 않는다. 현재 특정 캐릭터의 착용 상태는 이번 조사에서 직접 관측하지 않았다.

## 우선 확인된 공백

| 묶음 | 확인된 부족 | 현재 지원과의 구분 |
|---|---|---|
| 장비·가방 관리 | 장비 상자 보관, 장착·해제·교체, drop/trash/직접 전달 | 재료 보관·자동 무기 준비·일부 자동 장착은 있음 |
| 보급·상자 조작 | 수량을 남기는 부분 보관, 지정 상자, 임의 품목·수량 꺼내오기 | store는 허용 품목 전량; take는 제작 재료·배고픔 음식·농사 씨앗에 조건부 연결 |
| 장비 유지 | 수리·강화·업그레이드·분해 | 파손 감지·예비 무기·새 도구 제작은 있음; 수리는 초반부터, 나머지는 이후 우선순위 |
| 기지 물건 정리 | 일반 설치물 회수·재배치 지시, 잘못 놓은 울타리 회수 | PickupSkill은 있으나 기지 문/틈 특수 후보에 한정; 비벽 타일 회수는 실행 범위도 부족 |
| 이동 해결 | 막힌 물 구간을 골라 다리로 건너는 이동 계획 연결 | 다리 place·line·rect 자체는 지원; 별도 상위 계획은 가능 |
| 전투·동행 지시 | 특정 적 공격/처치 목표, 특정 동료를 따라가는 목표 | 하위 공격/동료 돕기/동료 따라가기 후보는 있음; 상위 follow는 호스트 전용; 지역 guard는 4a 개발 중 |
| 무기 운용 | 원거리 공격·방패·특수 사용 판단 | 근접 공격·일부 짧은 회피/복합 행동은 구현 |
| 채집 목표 | 임의 광물의 직접 gather 지정 | 상위 보고·검사는 흙/구리/주석/나무+보고된 음식만; 제작의 자동 재료 준비까지 같은 제한이라고 확대하지 않음 |
| 소모품 목적 선택 | 원하는 버프용 선소비·사전 보급 | 회복 포션·배고픔 식사는 지원; 체력/배고픔이 충분한 상태의 목적 소비는 연결 부족 |

공용 상자 접근은 단순 미구현과 구분한다. 기존 기록에는 호스트 상자 사용 금지가 사용자 결정으로 남아 있고, 현행 코드는 자기 상자만 사용한다. 기지 공간·계획 공유와 자원 접근 공유는 별개이므로 기존 정책 변경을 이번 조사에서 확정하지 않았다.

## 진행 중 및 뒤로 둘 범위

기지 build/guard·공유 계획·지도는 코어-안전지대 담당의 4a/4b 개발 범위로 분리했다. 4b는 그림 지도·CLI 이미지 확인·글자/그림 비교·구역 예약이며 둘레 넓히기는 단계5다. 일반 재배치·아이템 공유가 그 안에 포함됐다고 가정하지 않았다.

침대/리스폰 지정·거래·낚시·탈것/포탈·보스 상호작용은 현행 목표/후보에 없는 후속 범위지만, 이번에는 게임 동작별 실행 조건까지 전수 조사하지 않아 핵심 확정 공백과 구분했다. 부활 자체와 문 통과는 이미 있고 무덤 회수의 모든 일반 동작 가능성은 미확인이다.

## 우선순위 판단

초반 기지 생활에서는 장비를 골라 입기·보관하기 → 필요한 만큼 넣고 꺼내기 → 현장 가방 정리/물건 전달 → 도구 수리와 일반 설치물 재배치를 먼저 검토할 만하다. 다음은 지정 대상 전투·동행과 이동 문제 해결, 이후 무기 종류·버프·상위 광물 단계 확장이다. 이는 조사에 따른 권고이며 구현 범위나 정책 결정은 아니다.
