# 행동 제약 전반 해제

사용자는 감사에서 현재 제약으로 보고한 항목을 전반적으로 해제하라고 지시했다. 채집 허용 고정목록은 게임 지식 공개와 별개인 것으로 확인돼 제거 대상이다. 사람 시야와 본 것·보유품·본 제작대 레시피/재료로 지식 공개를 여는 정책은 유지한다.

범위: [감사 보고](../2026-11-07-제약감사/보고.md)와 상세01/02의 임의 작업량·계획길이·열린지시수·후보와 정보의 잘림·고정거리·기지/농장 범위·목표/허기 기반 후보 숨김을 해제한다. 생활 분류 기능 자체 대신 현재 설명한5항목 페이지 제한을 제거하는 것으로 해석한다. 옛 탐험 대표지점 압축을 제거하고 합의된 이동과 충돌하는 자동 선별을 정리한다. 새로 거점·농장 정책을 임의로 정하지 않는다.

사용자 추가 확인으로 사용자 부탁 수·계획 길이·장거리 이동·지원 행동 범위를 모두 포함한다. 감사에서 확인한 지원 행동 제약은 미구현이라는 이유로 제외하지 않는다. 손에 드는 도구/무기 유형 제한과 특정 적 전용 제어 등도 실제 선택→정상 입력→결과 관측까지 연결한다. 제한만 없앤 뒤 실행 가능한 것처럼 가짜 노출하지 않는다.

실제 게임 물품/슬롯/충돌/재료 조건, 정상 게임 요청, 소유권, 사용자 예산과 구독 보호, 입력 형식/정수 표현 경계와 실행중복 방지는 제약 해제와 구별한다. 한 번의 실행 묶음은 장기 목표량을 자르지 않아야 한다.
