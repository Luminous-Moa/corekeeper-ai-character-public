# 생활 트리 다음 단위: 일반 수리와 레벨 업그레이드

사용자는 첫 생활 트리의 지식그래프 저장 뒤 다음 단계 구현을 바로 진행하도록 지시했다. 첫 단위 코드·그래프 검수는 완료된 결과로 사용하고 반복 확인하지 않는다. 기존 작업 브랜치 생활선택-트리구현에서 이어 간다.

이번 결과는 정확한 장비의 일반 수리와 레벨 업그레이드를 기존 생활 트리와 직접 지정 실행에 연결하는 것이다. 장비·시설·비용을 AI가 비교해 고르고, 정상 게임 요청과 실제 장비/재료 변화·물품 회수를 확인한 뒤 원래 부탁을 이어 가게 한다. 내구 강화·자동 가공·거래·낚시는 별도 후속 단위다.

출발 코드는 첫 단위 공식 c4a0f5e38016c79567f880bbaea5e56e0eeae347이다. 다른 대화의 가방·장비 트리 통합이 진행 중이므로 별도 격리 worktree에서 작업하며 움직이는 기준을 자동으로 따라가지 않는다. 기존 공식 설정 수정과 타담당 후보를 보존한다. 통합 시에는 새 변경과 양쪽 흐름을 실제 대조한다.

일반 수리는 선택한 장비 하나의 정상 단일 요청을 사용한다. 레벨 업그레이드는 정상 대장간 입력 슬롯 투입→단일 업그레이드→변화 확인→가방 회수까지 연결한다. 무료 일괄 수리 helper나 가방에 둔 채 시설 준비를 생략하는 편법을 사용하지 않는다. 비용은 해당 장비·플레이어·시설의 현재 게임 규칙으로 조회하고 실제 소모와 상태 변화를 별도로 관측한다. 새 자원 공유 정책·소비 예산·최대레벨 자동 반복을 추가하지 않는다.

기존 트리 조회의 몸/대기/목표 보존, 직접 실행과 말단의 동일 입구, 정확 슬롯/variation/상태 바인딩과 재검증, 다른 행동의 목표 진척 제외를 유지한다. 요청 전송을 성공으로 세지 않고 장비 상태 변화와 회수를 구별한다.

기존 설치·실게임 보류는 유지한다. 실제 생산 코드의 대표 파이프라인과 직접 관련 회귀, Unity 컴파일 및 독립 검수 뒤 본 코드와 이번 변경의 지식그래프를 반영한다. 완료된 첫 단위 그래프의 재검수는 수행하지 않는다.
