# 행동 취소와 목표 종료의 판단 주체

사용자 결정. 코드가 자체 기준으로 AI의 유효한 선택을 강제 취소하는 분기를 전체 정비 대상으로 삼는다. 현재 행동을 계속할지, 스스로 취소할지, 다른 행동으로 전환할지는 AI가 선택한다. 현장 행동의 중단·전환은 Decisions가 담당하고 원래 부탁의 종료와 중요한 계획 변경은 위쪽 LLM이 판단한다.

구리 10/10은 관측된 수량 달성이다. 이를 현재 행동과 원래 부탁의 상태에 반영하고, 이미 선택한 다음 광맥으로의 이동이 여전히 가능하면 판단을 기다리는 동안 이어 간다. 수량을 이유로 진행 중인 몸 동작을 멈추거나 원래 갑옷 부탁을 끝내지 않는다. AI에게 명시적인 그만두기 선택을 제공한다.

정비 때는 목표 달성, 막힘, 시간 경과, 판단 호출 실패, 예약 응답 폐기 등에서 무엇이 실제로 끝났는지와 누가 취소를 결정했는지 확인한다. 대상 소실로 실행할 수 없어진 경우에는 사실과 이유를 보고해 AI가 다음 행동을 선택하게 한다. 뒤늦은 응답은 현재 대상·선택과 대조하며 이미 내린 새 AI 결정이나 사용자의 직접 중지 명령을 존중한다.
